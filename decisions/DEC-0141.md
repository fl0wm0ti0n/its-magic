## Context

Standalone TypeScript runtime can orchestrate lifecycle (US-0140) but cannot discover, start, observe, repair, or clean up real applications. Kit Python Connect / `dev_environment_lib` / `uat_probe_lib` remain Cursor/OpenCode host inputs — consume names and stack-detection semantics, do not become the runtime. `RunsStore.process_handles` today is `{id, run_id, reserved}` only. Operators need local + Docker core v1 plus typed WSL/SSH/remote-Docker adapters with fail-closed diagnostics and bounded self-debug, without nesting process lifecycle inside CommandRouter/GateEngine.

R-0138 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1 and closes architecture-owned pins: sibling npm name `@its-magic/app-runtime` (not `execution-runtime`), additive `process_handles` column names, `ExecutionBackend` matrix + **LOCKED** `BACKEND_*` / `APP_RUNTIME_*` / `PROCESS_*` reason codes, HEALTHCHECK status-only + AppRuntime-owned restart cap `APP_RUNTIME_RESTART_MAX` default 3, stack-profile port of `detect_stack_profile`, Connect handoff field names (no browser), cleanup/orphan reap, twelve `test_us0141_*` markers, and sprint seeds. It also closes research-critic informational NBs (`us0141res-*`).

A1 (one sibling package + compose RunsStore + CLI-first backends) is the simplest design that meets AC-1..AC-8.

### 2. Package + import boundary (DQ1 / AC-1)

### 3. `process_handles` additive schema + writer (DQ2 / AC-2)

Keep US-0140 columns `id`, `run_id`, `reserved` for back-compat. Additive columns **LOCKED**:

`phase_id`, `backend`, `identity_kind` (`process` \| `container` \| `service`), `identity`, `command`, `cwd`, `ports_json`, `url`, `readiness`, `started_at`, `crash_count`, `restart_count`, `log_ring_ref`.

- **Who writes**: `ProcessManager` via new `RunsStore` public methods (`upsertProcessHandle` / `listProcessHandlesForRun`). Workflow `reserveProcessHandle` remains a **claim token**; AppRuntime fills the row.
- **Log ring**: files under gitignored `.its-magic/runtime/logs/` + in-memory ring default **256 lines**; SQLite stores **refs**, not megabyte BLOBs. Compose US-0140 gitignore analog `**/.its-magic/runtime/`.
- **Reject** a second SQLite file. **Reject** SQLite as DONE/backlog authority (DEC-0140 held).

### 4. ExecutionBackend matrix + diagnostics (DQ3 / AC-3)

Interface **LOCKED** (Chump analog): `name()`, `execute()`, `health_check()`. Thin `DockerClient` so dockerode can swap later; **do not require dockerode** v1.

| Kind | Ids | v1 posture |
|------|-----|------------|
| Core (must work without adapters) | `local`, `docker` (`docker-local`) | Node `child_process.spawn` (local) + CLI-first `docker` / `docker compose` spawn |
| Typed adapters | `wsl`, `ssh` / `remote-docker` | `wsl.exe -d <distro> [--cd <linuxCwd>] -- <cmd>` with `wslpath`; `ssh -o BatchMode=yes -o ConnectTimeout=5` and/or `docker --context` / `DOCKER_HOST=ssh://` (key auth, known_hosts; password SSH unsupported) |
| Future stub | micro-VM / sandbox | `BACKEND_UNSUPPORTED` |

Connectivity **health_check before execute**. Missing binary / daemon / distro / SSH → fail-closed, **not** silent local fallback. Unsupported backend (AC-8) → `BACKEND_UNSUPPORTED`.

Compose US-0086 `remote.json` / `REMOTE_*` as **input target selection**. Do not overload `REMOTE_AUTOMATION_MODE_OFF` or `DEV_ENV_*` / `RELEASE_*` / `WORKFLOW_*` as the primary AppRuntime family.

### 5. Fail-closed reason codes (LOCKED)

**`APP_RUNTIME_*`**: `APP_RUNTIME_PROFILE_UNKNOWN`, `APP_RUNTIME_START_FAILED`, `APP_RUNTIME_HEALTH_FAILED`, `APP_RUNTIME_RESTART_CAP_EXHAUSTED`, `APP_RUNTIME_UNSUPPORTED_STACK`, `APP_RUNTIME_CLEANUP_FAILED`.

**`BACKEND_*`**: `BACKEND_UNKNOWN`, `BACKEND_UNAVAILABLE`, `BACKEND_DOCKER_UNAVAILABLE`, `BACKEND_WSL_UNAVAILABLE`, `BACKEND_SSH_UNAVAILABLE`, `BACKEND_UNSUPPORTED`, `BACKEND_CONNECTIVITY_FAILED`, `BACKEND_TIMEOUT`.

**`PROCESS_*`**: `PROCESS_CRASHED`, `PROCESS_ORPHAN_REAPED`.

Classification taxonomy **LOCKED**: `start_failed`, `health_failed`, `crash`, `timeout`, `connectivity`, `unsupported_stack`, `unsupported_backend`.

### 6. Stack discovery (DQ4 / AC-4)

Port `uat_probe_lib.detect_stack_profile` semantics into TypeScript (do **not** spawn Python; do **not** rewrite the Python lib). Order **LOCKED**: `package.json` → `node`; `pyproject.toml`/`setup.py` → `python`; `go.mod` → `go`; `*.csproj` → `dotnet`; `pom.xml` → `java`.

Unknown stack → fail-closed `APP_RUNTIME_UNSUPPORTED_STACK` **unless** operator override `DEV_SERVER_COMMAND` / profile `start_command` is present (deterministic fallback). `generated` README heuristic stays kit-side. Consume `.cursor/dev-environment.json` + Connect field names as **input**; AppRuntime **owns execution**.

### 7. Bounded remediation (DQ5 / AC-5)

AppRuntime-owned loop: capture logs → classify → optional **fresh DEV** session (`SessionSupervisor.spawn`, compose US-0136; do not rewrite supervisor) → rebuild/restart → stop at cap with `APP_RUNTIME_RESTART_CAP_EXHAUSTED`.

- **Cap source**: default **3**; override `APP_RUNTIME_RESTART_MAX` from **resolved config/scratchpad** if present. **No new RuntimeConfig domain / loader rewrite** (compose US-0138). Orthogonal to execute↔QA `AUTO_IMPLEMENTATION_LOOP` (do not share the same counter).
- **Docker HEALTHCHECK**: read status as a **health signal** only. AppRuntime **owns** restart. Daemon `--restart` is not the remediation owner.
- **Reject** unbounded restart; **reject** PM2/forever as ProcessManager.

### 8. Test/build evidence + log budget (DQ6 / AC-6)

Every test/build/start command through `ExecutionBackend.execute` persists §21.2 JSON: `{ command, backend, exit_code, duration_ms, stdout_ref, stderr_ref }` plus `reason_code?`. Large logs: full files on disk; **summarize** (head/tail + error-line extract, default model budget **8 KiB**). In-memory ring default **256 lines**; file refs in `process_handles.log_ring_ref`.

### 9. Connect/health + cleanup (DQ7 / AC-7)

Expose `url` / `ports` / `health` / `health_path` using US-0098 Connect **field names** (`connect_endpoint`, `health_path`, `service_id`, `container_id`, `env_refs` names-only). **US-0142 consumes**; this story does **not** drive Playwright/CDP.

- **Secrets**: never read `.env` (US-0085); redact Authorization/Cookie in logs (compose US-0135 `redact.ts` / US-0137).
- **Cleanup**: `ProcessManager.stop` after success, failure, cancellation (`AbortSignal`), and **runtime restart**. Compose US-0140 `discardOrphans` for **sessions**; AppRuntime **reaps process/container orphans** (`PROCESS_ORPHAN_REAPED`) — workflow does not kill apps.
- Health probes: TCP listen and/or HTTP GET `health_path` with timeout; process-alive is insufficient for AC-1/AC-7 URL exposure.

### 10. Layer B profiles vs micro-VM (DQ9)

Layer A held (US-0137 path/shell/secret/`policy_hash`). Layer B this story = execution **profiles** (`trusted_local` → `local`, `isolated_dev` → `docker`) per §26.3 — **not** micro-VM (`untrusted_repo` sandbox → `BACKEND_UNSUPPORTED`).

Do **not** rewrite KernelBridge, workflow/GateEngine/CommandRouter, config loaders, context-engine ranking, `noTools`, isolation loader, auth-models. Optional ToolBroker `itsm_app_*` unstub is a **seed**, not a rewrite of PolicyEngine tables.
