# DEC-0132: Explicit Cursor/OpenCode model configuration contract (four surfaces; reject generic `model.json`)

- Date: 2026-09-08
- Status: Accepted
- Story: `US-0132`
- Research refs: `R-0117` (DQ1–DQ10 LOCKED; `/research` auto-20260908-us0132; EARLY_RESEARCH architecture-phase Context7 `/websites/opencode_ai_v2` confirm — no official `model.json`; no new R-id)
- Composes on: **`US-0101` / `DEC-0086`** (Cursor catalog + tiers — unchanged), **`US-0102` / `DEC-0087`** (5-step precedence + v2 roles — unchanged), **`US-0130`** (critic pin overlay — unchanged), **`US-0123` / `DEC-0123`** (OpenCode per-role catalog + `opencode_model_catalog_apply.py` — unchanged), **`US-0112`** (example delivery), **`DEC-0039`** (local-file preservation), **`US-0121` / `DEC-0120`** (`--host` install/clean), **`US-0126` / `DEC-0126`** (reason-code table compose — additive `MODEL_CONFIG_*` rows only)
- Extends: `scripts/model_tier_validate.py --scope model-config` (inventory / unknown-path / schema-mix / both-host / gitignore row); diagnostics `provenance=` overlay on Cursor resolver; gitignore + clean-path exemptions for OpenCode locals
- Related: **`US-0131` / `DEC-0131`** (**DONE compose-only** — do not reopen; kit governance keys stay out of `opencode.json`; host-neutral resolver continues to ignore `MODEL_*`)
- Supersedes: none (companion to DEC-0131; **not** a second runtime-config matrix)

## Context

Operators need one documented contract for every model file Cursor and OpenCode actually use. Today that inventory is split: Cursor `.cursor/model-catalog.local.json` + scratchpad `MODEL_*`, OpenCode kit `.opencode/model-catalog.local.json` (materializer SOT), and OpenCode **host** `opencode.json{,c}` (`model` / `providers`). A generic `model.json` name is **not** an official OpenCode surface (https://opencode.ai/v2/docs/config/ + https://opencode.ai/v2/docs/models + Context7 `/websites/opencode_ai_v2`) and must not become an undocumented third kit SOT.

R-0117 locked DQ1–DQ10 and recommended approach **A1**. This DEC accepts A1, closes architecture deferred items (DQ1 path glob, DQ3 optional host-JSON read, DQ5 `HOST_COLLISION` distinct row, DQ4 clean exemption mechanism), and closes research-critic informational NBs (`us0132rsc-*`).

US-0131 / DEC-0131 remain **DONE compose-only**. This DEC does **not** reopen runtime-config ACs or reuse DEC-0131 as a second matrix.

## Decision

### 1. Approach A1 — explicit inventory + reject `model.json` + per-host diagnostics + `--scope model-config` (LOCKED)

| Option | Summary | Verdict |
|--------|---------|---------|
| **A1** | Four supported surfaces; reject generic `model.json`; Cursor vs OpenCode schemas stay separate; `opencode.json{,c}` is host file not kit SOT; per-host precedence diagnostics; extend `model_tier_validate.py --scope model-config`; gitignore + clean exemption for locals including `.opencode/model-catalog.local.json` | **Accepted** — meets AC-1..AC-8; composes DEC-0086/0087/0123/0131 |
| A2 | Alias `model.json` to OpenCode catalog or `opencode.json` | **Rejected** — third SOT / `--host both` ambiguity (DQ1) |
| A3 | Union / generic kit `model.json` SOT | **Rejected** — mixes Cursor tier/phase with OpenCode `provider/slug` |
| A4 | Dump kit catalog into `opencode.json` | **Rejected** — DEC-0131 + OpenCode host schema |

### 2. Canonical inventory — four surfaces, zero silent thirds (AC-1; DQ1 glob CLOSED)

| Owner | Path / keys | Kind |
|---|---|---|
| Cursor kit catalog | `.cursor/model-catalog.local.json` | Operator-local; gitignored; read-only resolver |
| Cursor scratchpad | `MODEL_*` / `MODEL_TIER_*` / `MODEL_RESOLVE` / `MODEL_CATALOG` / `MODEL_FALLBACK` / `MODEL_PROVIDER_MODE` / `MODEL_TIER_DEFAULT` / `MODEL_SOVEREIGN-CRITIC` | Cursor-only; live slugs in `.cursor/scratchpad.local.md` |
| OpenCode kit catalog | `.opencode/model-catalog.local.json` | Operator-local; gitignored; materializer SOT |
| OpenCode **host** runtime | local-only `opencode.json{,c}` (repo root, `.opencode/`, or user global) | OpenCode's own `model` / `providers` / agents; kit never writes |

**Unknown-path scan (kit-owned, repo-scoped only)**: `model.json` and `model.jsonc` at **repo root**, **`.cursor/`**, and **`.opencode/`**. Present → `MODEL_CONFIG_PATH_UNKNOWN`. Do **not** alias. Do **not** scan `~/.config/opencode/model.json` (home-dir OpenCode files stay OpenCode-owned). `--host both` never maps the generic file to either host.

Examples (framework, refreshable): `.cursor/model-catalog.local.example*.json`; `template/.opencode/model-catalog.local.example.json`. Never deliver active catalogs or `opencode.json`.

### 3. Separate schemas (AC-2)

- Cursor keeps DEC-0086 v1 tiers + DEC-0087 v2 roles. Cursor resolver **must not** read `.opencode/model-catalog.local.json`.
- OpenCode keeps DEC-0123 per-role `provider/slug`. Materializer **must not** read `.cursor/model-catalog.local.json` or scratchpad `MODEL_*`.
- Cross-offer (Cursor schema at OpenCode catalog path, or reverse) → `MODEL_CONFIG_SCHEMA_MIX`.
- No union schema (DEC-0123 A4 remains rejected).

### 4. Per-host precedence + diagnostics (AC-3; DQ2/DQ3 CLOSED)

**Cursor (compose — do not amend DEC-0086/0087/US-0130)**:

1. `MODEL_<PHASE>` direct slug
2. `MODEL_TIER_<PHASE>`
3. `MODEL_RESOLVE=role_catalog` → catalog `roles`
4. `MODEL_TIER_DEFAULT`
5. Cursor stable alias

US-0130 overlay: `MODEL_SOVEREIGN-CRITIC` > catalog `roles.critic` > opposition / `dev` fallback. Collision still `CROSS_MODEL_DEGRADED_MODE`.

**US-0132 add**: resolver/validator diagnostics emit `provenance=` of the winning step (`host=cursor`, path, step). Absent catalog + `alias_only` remains **valid** (not invalid).

**OpenCode — two independent layers; kit does not merge them**:

Kit materializer (DEC-0123 compose):

1. `.opencode/model-catalog.local.json` **absent** → no-op; installed agents keep `model:` omitted
2. Catalog **present** → validate → inject `model: provider/slug` into **installed** `.opencode/agents/<role>.md` only
3. Present + unknown/empty/placeholder slug → `OPENCODE_MODEL_SLUG_UNKNOWN`; malformed catalog → `MODEL_CATALOG_INVALID` `scope=opencode-catalog`

OpenCode host runtime (official docs; kit does not intercept sessions):

1. Session / CLI per-run selection (does not rewrite config)
2. Agent / command `model` (frontmatter or `opencode.json` `agents.*.model`) — materializer output is consumed here
3. Root `opencode.json{,c}` `model` default when the agent has no model
4. OpenCode newest-available enabled-model fallback

**Optional kit diagnostic read of `opencode.json{,c}`** (DQ3 deferred CLOSED): **yes**, names-only (`model` string / agent model ids), fail-open if absent. Malformed **present** file → `MODEL_CATALOG_INVALID` `scope=opencode-host` (reuse scoped invalid; not confused with absent). Kit **never writes** `opencode.json{,c}`.

`--host both`: both catalogs may coexist; diagnostics emit **per-host** provenance. No union.

### 5. Reason-code family (AC-5; DQ5 HOST_COLLISION CLOSED)

Reuse existing host-scoped codes; add contract-layer codes for inventory/mix/unknown-path only. Do **not** reuse `HOST_CONFIG_*`. Do **not** invent `OPENCODE_MODEL_CATALOG_INVALID`.

| Code | When |
|---|---|
| Existing Cursor `MODEL_*` (`MODEL_CATALOG_INVALID`, `MODEL_SLUG_UNKNOWN`, `MODEL_OVERRIDE_SLUG_UNKNOWN`, `MODEL_ROLE_SLUG_UNKNOWN`, `MODEL_CATALOG_SCHEMA_V2_INVALID`, `MODEL_TIER_INVALID`, `MODEL_RESOLVE_FALLBACK`) | Unchanged Cursor resolver/validator |
| Existing `OPENCODE_MODEL_SLUG_UNKNOWN` | OpenCode catalog present + unknown/empty/placeholder slug |
| Existing `MODEL_CATALOG_INVALID` `scope=opencode-catalog` | Malformed OpenCode **kit** catalog JSON |
| Existing `MODEL_CATALOG_INVALID` `scope=opencode-host` | Malformed **present** `opencode.json{,c}` when optionally read |
| **New** `MODEL_CONFIG_PATH_UNKNOWN` | Generic `model.json{,c}` at the three repo-scoped locations |
| **New** `MODEL_CONFIG_SCHEMA_MIX` | Cursor catalog schema offered as OpenCode catalog (or reverse) |
| **New** `MODEL_CONFIG_HOST_COLLISION` | Undeclared `model.json{,c}` under `--host both` — **distinct row** alongside `PATH_UNKNOWN`; never pick a host |

`--host cursor|opencode` + `model.json` → `PATH_UNKNOWN` only. `--host both` + `model.json` → `PATH_UNKNOWN` **and** `HOST_COLLISION`. Absent optional file ≠ invalid.

### 6. Materializer invariants (AC-4; DQ7)

Confirm DEC-0123 plus:

1. **Idempotent**: second apply with unchanged catalog yields the same `model:` frontmatter
2. **Never write** `template/.opencode/agents/**`
3. **Never write** the active local catalog (read-only input)
4. **Never write** Cursor catalog, scratchpad, or `opencode.json{,c}`
5. **No credentials / real operator slugs** in examples or templates
6. Absent catalog remains no-op exit 0

### 7. Gitignore + installer + clean exemption (AC-6, AC-7; DQ4 mechanism CLOSED)

**Gitignore (defense in depth)**:

- Add explicit `.opencode/model-catalog.local.json` to **root** and **template** `.gitignore` (today only `.cursor/model-catalog.local.json` is listed).
- Keep `template/.opencode/.gitignore` `*.local.json` + `.opencode/opencode.json{,c}` rows.
- Do **not** force-gitignore repo-root `opencode.json{,c}` (teams may commit non-secret project defaults). Credentials stay in OpenCode `/connect`.

**Never overwrite** on install / missing / upgrade: `.cursor/model-catalog.local.json`, `.opencode/model-catalog.local.json`, `.cursor/scratchpad.local.md`, repo-root and `.opencode/` `opencode.json{,c}`.

**Clean exemption (simplest DEC-0039-class)**: **exclude-from-clean** named locals — do **not** copy-aside/restore. `[opencode_clean_paths] .opencode` must **not** delete `.opencode/model-catalog.local.json` or `.opencode/opencode.json{,c}`. Cursor clean must not delete `.cursor/model-catalog.local.json` / `.cursor/scratchpad.local.md`. Shrinking `--host` must not delete the other host’s locals (US-0121 compose).

**Example delivery**: Cursor examples on `--host cursor|both` (US-0112); OpenCode example catalog on `--host opencode|both`. Never deliver `opencode.json` or active catalogs. Manifest stays additive.

### 8. Validator + tests + docs (DQ8–DQ10)

- **Extend in place** `scripts/model_tier_validate.py`. Keep default unscoped Cursor checks and `--scope opencode-catalog`. Add `--scope model-config` (inventory + unknown `model.json` + schema-mix + both-host coexistence + gitignore row). Do **not** fold into `opencode-catalog`. Reject a new `opencode_model_catalog_validate.py` as the default.
- Ten `test_us0132_*` static/fixture markers (R-0117 DQ9); no live OpenCode CI probe.
- Runbook h2 `## Cursor/OpenCode model configuration contract (US-0132)` (active + template byte-identical) + README pointer. Compose cross-link only on US-0126 OpenCode host runbook and US-0131 runtime-config h2 (do not rewrite those contracts). US-0126 table gains additive `MODEL_CONFIG_*` rows only.

## Consequences

- Execute implements A1 without reopening DQ1–DQ10 or DEC-0131.
- Cursor 5-step chain and OpenCode materializer stay composed, not rewritten.
- Generic `model.json` fails closed; operators migrate to the named host surface.
- Clean/install cannot wipe operator model locals.

## Alternatives considered (summary)

See options table in §1. Additional rejects: scanning home-dir `~/.config/opencode/model.json`; copy-aside clean; dumping kit keys into `opencode.json`; amending DEC-0086/0087/0123/0131; new validator script as default; `HOST_CONFIG_*` reuse.
