# DEC-0147: Standalone install, update, and existing-project adoption

- Date: 2026-09-17
- Status: Accepted
- Story: `US-0147`
- Research: `R-0144` (DQ1–DQ10 LOCKED; `/research` auto-20260917-us0146)

## Context

Operators need a documented, non-destructive install/update/adoption path so the standalone runtime (`itsm`, US-0146 CLI/TUI) can operate in the same repository as Cursor/OpenCode hosts without rewriting canonical artifacts, locals, or host trees. Kit installers remain template-focused; `package.json` `files` omit repo-root `standalone/`. US-0146 delivered `@its-magic/cli`, `@its-magic/tui`, and `runtime-core/src/operator/` — this story **wires** them via install hooks, not by rewriting operator facades.

R-0144 locked DQ1–DQ10 and recommended **A1 (A\*)**. `decision_gate=false`. This DEC accepts A1 and pins manifest paths, hook order, shim locations, adoption classifier, metadata file, reason codes, and ten `test_us0147_*` contract markers.

## Decision

1. **Approach A1** — extend **triple-installer parity** (`installer.py` / `installer.ps1` / `installer.sh`) and `installer-owned-paths.manifest` (active + `template/` mirror) with additive **standalone product bootstrap**: template-mirrored workspace under **`.its-magic/standalone/`**, post-install hook **`bootstrap_standalone_runtime_installer_hook`**, **`itsm` shim** (`.its-magic/bin/itsm`; optional repo-root `bin/itsm` only when operator opts in), **kernel-bridge preflight** before shim write, **`runtime-metadata.json`**, explicit **`itsm setup browser`**, adoption **`classifyProjectAdoptionProfile`** composing US-0134 locate. Reject adding root `standalone/` to npm `files`, host tree rewrite, forced scratchpad migration, US-0148 daemon install, npm-publish, and duplicate kernel validators outside kernel-bridge.
2. **Template mirror (DQ1)** — ship `template/.its-magic/standalone/` (or architecture-pinned equivalent) mirroring repo-root `standalone/` layout (apps, packages, lockfile). Published kit continues `files: ["template/", …]` without root `standalone/`. **FRAMEWORK_KIT_REPO=1** kit-dev may pin in-tree `standalone/` (symlink/path) to avoid duplicate `node_modules` — default **in-tree** for framework repo only.
3. **Installer hook (DQ2)** — `bootstrap_standalone_runtime_installer_hook` in `installer.py`, invoked from post-install ordering **after** host-config example refresh and **before** runbook bootstrap (exact index pinned in architecture). PS1/sh invoke the same Python subcommand. Repair: `its-magic --mode upgrade --standalone-bootstrap` (and `--mode missing` path) idempotent. Failure: **`STANDALONE_BOOTSTRAP_FAILED`** with stderr capture.
4. **Adoption (DQ3)** — `classifyProjectAdoptionProfile(target_root)`: **fresh** (three-marker locate fails), **existing-its-magic** (locate succeeds — adopt without rewriting `docs/product/backlog.md`, `handoffs/`, `decisions/`, sprint history), **host_profile** advisory (`cursor-only`, `opencode-only`, `both-host`, `standalone-only`). Fail-closed **`ADOPT_PARTIAL_MARKERS`** when 1–2 of 3 kernel markers match. Compose `locateProjectKernel` — do not fork marker list. Do not delete host folders.
5. **Fresh init (DQ4)** — `template/` manifest skeleton only; **no** US-0001..US-0132 backlog clone. Optional starter backlog at architecture-pinned path; default minimal template backlog.
6. **Preservation (DQ5)** — manifest **`install_include_paths`** vs **`deny_overwrite`** (locals, credentials, browser profiles, `.its-magic/runtime/**`, operator auth stores, project source outside manifest). Upgrade follows US-0018 refresh semantics. Interrupted update: staging `.its-magic/install-staging/<run_id>/`; success updates `runtime-metadata.json`; failure rollback staging only + **`INSTALL_INTERRUPTED_ROLLBACK_OK`** with preserved user layers list.
7. **Kernel compatibility (DQ6)** — preflight `getKernelVersion` + `readContractManifest` + semver range before `itsm` shim; persist `.its-magic/standalone/runtime-metadata.json` (`kernel_version`, `contract_schema_version`, `supported_range`, `validators[]` hash). Surface **`KERNEL_*`** (US-0134); new **`INSTALL_*`** codes only where needed — no handshake fork. No skip when `FRAMEWORK_KIT_REPO=1`.
8. **Browser (DQ7)** — explicit **`itsm setup browser`** scoped to `.its-magic/standalone/node_modules` (compose US-0142). Install does **not** silently download browsers unless `ITS_MAGIC_INSTALL_BROWSER=1`. Offline: **`INSTALL_BROWSER_OFFLINE`**. Failed browser setup does not roll back framework install; `browser_prereq=missing` in metadata.
9. **Scratchpad (DQ8)** — v1 install does **not** invoke `LegacyScratchpadAdapter` migration. Diagnostics may WARN **`SCRATCHPAD_LEGACY_KEYS_PRESENT`**. Host-neutral `.its-magic/config*.json` refresh unchanged.
10. **Uninstall (DQ9)** — `its-magic --mode uninstall-standalone` removes `.its-magic/standalone/`, `itsm` shims, install-staging, runtime-metadata; **preserves** `.cursor/`, `.opencode/`, `its_magic/` framework copy, user locals, project source. Version mismatch → advisory **`KIT_VERSION_COEXISTENCE`**.
11. **Tests** — ten hermetic pytest/installer fixtures + optional contract smoke for `itsm --version` after bootstrap (compose US-0055). Kit publish guard unchanged unless template standalone mirror added to manifest tests.
12. **Compose-only** — US-0140..US-0146 DONE (US-0146 install wiring IN). US-0145 / US-0148 bodies OUT. BUG-* compose only. Do not restore `.opencode/commands/auto.md`. No kit `cli.json` or plugin `its-magic-auto/tui.json`.

## Risks

| Risk | Mitigation |
|------|------------|
| npm `files` drift breaks publish guard | Template mirror only; `test_us0147_fresh_install_manifest_parity` |
| PS1/sh hook fork | Single Python hook; US-0055 parity |
| Destructive adopt | deny_overwrite + no backlog clone; `test_us0147_adopt_*` |
| Partial kernel markers corrupt state | `ADOPT_PARTIAL_MARKERS` fail-closed |
| Silent Playwright download in CI | Explicit `itsm setup browser`; `test_us0147_browser_setup_explicit_gate` |
| Dual version truth | Single `runtime-metadata.json`; kernel preflight |
| US-0148 scope creep | In-process operator session only (US-0146); no daemon install |
