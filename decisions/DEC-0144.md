# DEC-0144: Optional sovereign runtime composition in runtime-core

- Date: 2026-09-15
- Status: Accepted
- Story: `US-0144`
- Research: `R-0142`

## Context

US-0143 schedules a fresh critic session but intentionally leaves its content disabled. The existing sovereign Python libraries own ledger, memory, critic, role-review, deferral, and convergence schemas. Runtime-core needs an opt-in typed integration without making an arbitrary Python runner, changing the US-0143 scheduler, or replacing producer roles.

## Decision

1. Add a nested `SovereignRuntime` to `@its-magic/runtime-core`; do not add a sibling package or Pi dependency.
2. Add a closed `KernelBridge.runSovereignOperation()` API. The only operations are `memory_digest`, `critic_model`, `role_review_plan`, `decision_session_append`, `deferral_append`, `deferral_list`, `drain_candidate_gate`, `convergence_evaluate`, and `partial_delivery_write`.
3. Admit operations only when `kernel-contract.json` declares them and the sovereign artifact path resolves. The bridge accepts and returns versioned, bounded JSON envelopes and maps malformed input/output, missing operation, timeout, and subprocess failure to `KERNEL_SOVEREIGN_*` codes.
4. `SOVEREIGN_RUNTIME=0` is the default. At `0`, no sovereign bridge call, memory read, sidecar write, sovereign review, convergence evaluation, or sovereign candidate gate is run; the existing US-0143 `CROSS_MODEL_REVIEW=1` scheduling-only critic session remains unchanged.
5. When enabled, assemble a bootstrap before fresh producer spawning in this order: phase context, bounded memory digest, role objective. The supervisor must attest the bootstrap context hash and acknowledge one delivery before producer work.
6. Preserve the 12-field decision ledger. Store session/model metadata in the append-only `handoffs/sovereign_decision_sessions/<run>.jsonl` sidecar, guarded by a matching ledger entry, deterministic event ID, idempotency, and fail-closed torn-write handling.
7. Keep `advance_sovereign_loop()` candidate generation separate from materialization. `SovereignRuntime.gateDrainCandidate()` is the sole materialization boundary only for US-0144 sovereign-generated candidates, and explicit `SOVEREIGN_DRAIN_AUTO_ACCEPT=0` requires per-candidate operator acceptance regardless of preset expansion. Legacy US-0143 drain materialization is unchanged while sovereign runtime is disabled.
8. Return a discriminated sovereign result through workflow hooks and `AutoRunResult`. Open blocking critic findings alone block convergence; smoke surrogates never assert browser success.

## Consequences

- Source changes are limited to runtime-core, kernel-bridge, role-runtime, `kernel-contract.json`, a dedicated Python bridge dispatcher, and US-0144 contract tests.
- `CommandRouter` route selection, US-0143 drain mechanics, GateEngine release ordering, the Python sovereign schemas, backlog/acceptance ownership, US-0145 parallel work, US-0146 UI work, and `.env` access remain out of scope.
- Twelve hermetic contract tests (R-0142 IDs): `test_us0144_kernel_bridge_admission`, `test_us0144_bridge_json_timeout_fail_closed`, `test_us0144_pre_spawn_context_order`, `test_us0144_memory_bounds_default_off`, `test_us0144_model_collision_degraded`, `test_us0144_supplementary_manifest_reviews`, `test_us0144_ledger_schema_preserved`, `test_us0144_sidecar_idempotent_torn_write`, `test_us0144_drain_gate_preset_zero`, `test_us0144_per_candidate_operator_decision`, `test_us0144_blocking_only_convergence_smoke_truth`, `test_us0144_caps_progress_partial_delivery_boundaries`.
