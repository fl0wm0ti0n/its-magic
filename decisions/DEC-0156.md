# DEC-0156: Phase-child continuation-pair + terminal-state-reconcile obligation at phase boundaries

- Date: 2026-10-25
- Status: Accepted
- Bug: `BUG-0044`
- Research: `R-0176` (F1–F7 RESOLVED/LOCKED, approach **A**)
- Composes on: DEC-0153 (phase-child-owned paired continuation record, state-first), DEC-0038 (strict runtime proof, 6-tuple hash), and the release UAT terminal-state gate (release.md US-0039). Amends nothing; the DEC-0153 child-owned / parent-spawn-only split is preserved unamended.

## Context

BUG-0044 is the "phase child does not complete its canonical handoff/reconcile obligations before STOP" class. A full scan of both hosts' phase-child command contracts (R-0176 F1) shows the DEC-0153 "Continuation contract" section is codified on only a subset — `research`, `architecture`, and the `auto` parent — and is **absent** on the phase children where the defect manifested (`discovery`, `execute`, `sprint-plan`, `qa`, `verify-work`, `release`, `closure`). Consequence: the continuation-pair + terminal-state-reconcile obligation is implicit (parent `auto.md` + role knowledge) rather than codified per child, which is exactly why the omission is intermittent and recurring (US-0164 `/sprint-plan` pair-missing; US-0164 `/verify-work` left `uat.json` in the QA lifecycle state → `/release` fail-closed `RELEASE_UAT_INCOMPLETE`; the US-0163 recurrence).

Two distinct obligations are at stake. The first — writing the DEC-0153 state-first continuation pair (state-bottom + brief-top, byte-identical, strict 6-tuple proof hash) before STOP — is already owned by DEC-0153/DEC-0038; it is not re-decided here, only re-codified per child and enforced by a deterministic self-check. The second — leaving phase-owned lifecycle artifacts in the terminal state for the child's own phase before STOP — is a **NEW normative phase-child obligation** (AC-2). It is not merely the pair-write, so it is decided here as DEC-0156, composable on DEC-0153/DEC-0038 + the existing release UAT gate. US-0163 and US-0164 are citations only, not edited; BUG-0015..BUG-0043 are not reopened.

## Decision

1. **A1 (primary) — the additive, host-neutral "Continuation + terminal-state reconcile contract" is codified on each remediation phase-child command.** The remediation set is `discovery.md`, `execute.md`, `sprint-plan.md`, `qa.md`, `verify-work.md`, `release.md`, `closure.md`, on the **OpenCode host (primary; the observed `environment`)** with `.cursor/commands/*.md` + `template/` active/template byte-parity where the file exists (R-0174 / BUG-0037 host-parity precedent). The exact per-file section text and placement are locked in `docs/engineering/architecture.md` `# BUG-0044` (Lock 1); the execute phase applies it verbatim. The parent `auto.md` contract is NOT edited (it already carries the spawn-only + repair-path contract). The auxiliary `plan-verify`/`intake`/`refresh-context` children are OUT of the remediation set (intake uses the distinct DEC-0069 script refresh, not the DEC-0153 pair; R-0176 Risk 7).

2. **A2 — a read-only, deterministic pre-STOP self-check helper is composed on the existing pair SOT; it does NOT re-implement pair logic.** `scripts/opencode_auto_bridge.py` gains `phase_boundary_self_check(repo, *, writer_role, state_json, brief_json) -> dict` (architecture decision: extend the existing module, NOT a thin new module, so the child-owned/parent-spawn-only split stays in one SOT). It is read-only and reason-coded: it composes on `validate_resume_pair(writer_role=<own role>)` and the strict 6-tuple hash via `token_cost_lib.compute_strict_proof_hash`, re-reading both sides and asserting byte-identity; it returns the `validate_resume_pair` result verbatim (so `RESUME_BRIEF_STALE` / `RESUME_BRIEF_UNPARSEABLE` and the retained predicate are reused) and grants **NO** parent authority (a `writer_role` of `auto`/`parent`/`orchestrator` is rejected by the composed `validate_resume_pair` → `RESUME_BRIEF_STALE` / `unauthorized_writer_role`). `reset_resume_pair_registry_for_tests` is reused for test isolation. Active/template `opencode_auto_bridge.py` pair stays byte-identical. The helper is an **enabler, not the fix**: without A1 the children still have no obligation to call it (R-0176 Risk 3).

3. **Deterministic pre-STOP self-check steps, locked (Lock 1).** Before emitting its STOP reason, every remediation phase child must: (1) append the state-bottom checkpoint with the canonical pair JSON; (2) compute the strict 6-tuple proof hash via `token_cost_lib.compute_strict_proof_hash(orchestrator_run_id, runtime_proof_id, phase_id, role, proof_issued_at, proof_ttl_seconds)`; (3) prepend the **byte-identical** brief-top record (temp-file-plus-replace, per `_write_resume_pointer_block`); (4) **re-read both sides and assert byte-identical + `validate_resume_pair(writer_role=<own role>)` → `ok=true`** (via the A2 self-check) before STOP. Cross-file atomicity is deliberately NOT claimed (per `_write_resume_pointer_block`); the validation rule — re-run by the child pre-STOP and by the parent post-spawn — is the safety boundary (R-0176 Risk 5).

4. **Terminal-state-reconcile (the NEW obligation, AC-2; Lock 3).** Each remediation phase child leaves the lifecycle artifacts it owns in the **terminal state for its own phase** before STOP. The per-phase terminal-state-reconcile table (which artifact each phase owns and its terminal state) is locked in `docs/engineering/architecture.md` `# BUG-0044`, with the `uat.json`/`uat.md` verify-work row as the canonical example (`status=VERIFY_PASS` / `phase_id=verify-work` / `uat_lifecycle=verify_work_complete_release_pending`). This composes on the existing release UAT gate (release.md US-0039) but is **not** a new reason code: a stale lifecycle state still fails the release gate with the existing `RELEASE_UAT_INCOMPLETE`; the child **prevents** the stale state, the gate still **detects** it fail-closed (R-0176 Risk 2).

5. **The parent stays spawn-only; no parent proof-minting; `RESUME_BRIEF_AUTO_REFRESH=0` absolute (AC-3; Lock 4).** The parent (`auto.md`) validates the child's pair via `validate_resume_pair` only and spawns; it never writes `state.md` or `resume_brief.md`, never mints a proof, and never refreshes the brief. A parent/`auto`/`orchestrator` `writer_role` is rejected by `validate_resume_pair` → `RESUME_BRIEF_STALE` / `unauthorized_writer_role`. The repair-only path (parent spawns one fresh `writer_role` repair child for the same `completed_phase`) remains the documented last-resort remedy but is **not** the prevention mechanism (defense-in-depth). `RESUME_BRIEF_AUTO_REFRESH=0` and `CROSS_MODEL_REVIEW=0` are unchanged; no repair-only re-mint or separate repair child is required for the recurrence on a later run (AC-5, F6).

6. **Fail-closed taxonomy unchanged; no new reason code (AC-4; Lock 5).** The missing/conflicting-pair case remains a deterministic fail-closed stop reusing `RESUME_BRIEF_STALE` (absent/invalid evidence, predicate retained) and `RESUME_BRIEF_UNPARSEABLE` (syntax), plus the `RUNTIME_PROOF_*` family; the stale-lifecycle-artifact case reuses `RELEASE_UAT_INCOMPLETE` at the release gate. No new uppercase code is introduced. The contract-test surface is `tests/bug0044_phase_boundary_pair_contract_test.py` (6 items; Lock 5), authored in the execute phase, not here.

**REJECTED:** (a) a new standalone pair-writer script that mints the pair for the child (re-creates the writer the child must own; blurs the child-owned/parent-spawn-only split); (b) A3-only parent-side validation tightening as the primary fix (makes the stall clean but does not prevent the omission at the source); (c) a new reason code for the stale-lifecycle-artifact case (reuse `RELEASE_UAT_INCOMPLETE`); (d) a new `MODEL_*` / governance key to force the self-check (US-0132 boundary — `MODEL_*` ignored; the self-check is a contract + read-only helper); (e) reopening US-0163/US-0164/BUG-0015..BUG-0043 (citations only; additive-only); (f) pulling intake (PO) into the DEC-0153 pair surface (intake uses the distinct DEC-0069 script refresh); (g) a thin new module for A2 over extending the existing SOT (one SOT keeps the child-owned/parent-spawn-only split intact).

## Consequences

- Each remediation phase-child command contract gains the locked "Continuation + terminal-state reconcile contract" section (OpenCode primary; `.cursor` + `template` byte-parity where the file exists). The parent `auto.md` is not edited.
- `scripts/opencode_auto_bridge.py` (+ template twin, byte-identical) gains `phase_boundary_self_check`; no pair logic is re-implemented — it composes on `validate_resume_pair` + `compute_strict_proof_hash`. `token_cost_lib.py` is not edited.
- The release UAT gate (release.md US-0039) is unchanged; the terminal-state-reconcile obligation is additive on the child, so `RELEASE_UAT_INCOMPLETE` remains the deterministic detection for any stale UAT lifecycle state.
- No new reason code; `RESUME_BRIEF_STALE` / `RESUME_BRIEF_UNPARSEABLE` + `RUNTIME_PROOF_*` + `RELEASE_UAT_INCOMPLETE` are reused. `RESUME_BRIEF_AUTO_REFRESH=0` and `CROSS_MODEL_REVIEW=0` unchanged. The DEC-0069 intake refresh is distinct and unchanged.
- `tests/bug0044_phase_boundary_pair_contract_test.py` (6 `test_bug0044_*` items) is authored in the execute phase; this decision does not implement it.
- No `.env` read, no npm publish, no git commit/push occurs here. BUG-0044 stays **OPEN/P1**; AC-1..AC-5 and its acceptance row stay unchecked. No sprint is created.
