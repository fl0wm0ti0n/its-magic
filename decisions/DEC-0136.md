## Context

The standalone runtime still trusts prompts for phase/role isolation: nothing forces a fresh Pi session per producer/review/execute-QA rework, nothing emits kernel-bound spawn/start/end facts, and nothing fail-closes reused session IDs or orchestrator mutation tools.

R-0128 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1 and closes architecture-owned items: `role-runtime` TypeScript surfaces, continuation allow-list, RoleCatalog schema (DEC-0051 port + extra catalog rows), sidecar attestation fields + `kernel_process_instance` encoding, fail-closed `SESSION_*` / `ATTESTATION_*` inventory, TypeScript orchestrator scheduling-only spawn gate, and the ten `test_us0136_*` markers. ### 3. SessionSupervisor (DQ1 / DQ2 / AC-1) — LOCKED

Supervisor is constructed with an injected `AgentKernel`. Production + CI keep the kernel's existing `SessionManager.inMemory(cwd)` (DEC-0133 `agentDir` isolation held — not `~/.pi/agent`, not the target project). Do **not** switch the production factory to `SessionManager.create` / `continueRecent` / `open` / `forkFrom`.

```ts
interface ContinuationContract {
  schema_version: 1;
  phase_id: string;
  role_id: string;
  kernel_session_id: string;
  allowed_ops: Array<"run" | "steer">;
}

interface SpawnRequest {
  phase_id: string;
  role_id?: string;
  orchestrator_run_id: string;
  model_id: string;
  parent_phase_session_id?: string | null;
  continuation?: ContinuationContract;
  tools?: string[];
  iteration_key?: string;
}

interface SupervisedSession {
  readonly kernelSession: KernelSession;
  readonly kernel_session_id: string;
  readonly fresh: boolean;
}

interface SessionSupervisor {
  spawn(req: SpawnRequest): Promise<SupervisedSession>;
  end(kernel_session_id: string): Promise<void>;
  discardOrphans(): Promise<void>;
}
```

**Fresh `createSession` per:** producer phase, review/critic phase, and every execute#N / QA#N rework iteration (`iteration_key` change counts as a new spawn). Crash / restart / orphan = deny continuation; discard + spawn fresh.

**Allow-list (same `KernelSession`, same `sessionId`):** process-local, same-phase `run` / `steer` only (owned `KernelSession`; Pi `followUp` queue is not exposed — map in-session follow-up to `steer`). ContinuationContract is **in-memory only** (never written to backlog/acceptance/decisions). Process restart ⇒ no contract ⇒ `SESSION_CONTINUATION_DENIED`.

**Default-deny across phase boundaries:** Pi `SessionManager.continueRecent` / `forkFrom` / `open` / `inMemory(..., entries)` / `AgentSessionRuntime.fork` / `newSession({ parentSession })`. Missing/expired/mismatched contract, `allowed_ops` including fork/resume, or `phase_id` / `iteration_key` change → `SESSION_CONTINUATION_DENIED`.

`parent_phase_session_id` on critic/review attestations is a **lineage pointer**, not a transcript import.

### 5. Attestation spawn/start/end + hash (DQ4 / AC-3) — LOCKED

Runtime (not the model) emits three sidecar records per session: **spawn**, **start**, **end**. Bound fields:

| Field | Source |
|---|---|
| `orchestrator_run_id` | scheduler |
| `phase_id` / `role_id` | RoleCatalog resolve |
| `kernel` | `"pi"` |
| `kernel_session_id` | `KernelSession.sessionId` (`session.sessionId`) |
| `kernel_process_instance` | `${bootUuid}:${pid}` — supervisor boot `crypto.randomUUID()` + `process.pid` (in-process Node; not OS sandbox) |
| `model_id` | DEC-0135 ModelRouter provenance slug |
| `context_pack_hash` | **stub** `sha256` of canonical empty/placeholder pack JSON until US-0139 |
| `policy_hash` | **stub** `sha256` of RoleCatalog snapshot + spawn tool-allowlist until US-0137 |
| `created_at` / `started_at` / `ended_at` | runtime clocks |
| `parent_phase_session_id` | prior producer session id or `null` |
| `fresh` | `true` iff new `createSession` and no continuation contract |
| `attestation_event` | `spawn` \| `start` \| `end` |
| `attestation_hash` | SHA-256 of canonical sorted-key JSON of the sidecar **without** this field |

**Do not extend** `compute_strict_proof_hash` / DEC-0038 tuple. Kit envelope (`runtime_proof_id` / `proof_hash` / TTL) stays the isolation gate. Sidecar `attestation_hash` is a **separate** hash over kernel session facts.

### 6. Sidecar persistence (DQ5 / AC-4) — LOCKED

- Repo artifacts remain canonical lifecycle memory (§27.1). Do **not** write kernel session ids into backlog/acceptance/decisions.
- **v1 store**: in-memory session registry is the live SOT; optional gitignored JSONL under the standalone OS config run dir (compose DEC-0135 OS config family: XDG / `%APPDATA%` / macOS Application Support `its-magic/runs/<orchestrator_run_id>/session-attestations.jsonl`) or a temp run dir. **Never** the project tree. SQLite operational store (§27.2) is **deferred**.
- Isolation evidence **required fields** (US-0048 / DEC-0029) + DEC-0038 envelope stay **byte-compatible**. Standalone kernel facts live under an additive `standalone_attestation` object. Python validators **ignore unknown keys**.
- Missing sidecar when standalone supervisor ran → `ATTESTATION_MISSING`. Hash mismatch → `ATTESTATION_HASH_MISMATCH`. Sidecar `kernel_session_id` ≠ live session → `ATTESTATION_KERNEL_SESSION_MISMATCH`. Stale kit proof → reuse `RUNTIME_PROOF_STALE` (do not invent a second TTL algorithm).

- `SESSION_CONTINUATION_DENIED`
- `SESSION_TRANSCRIPT_CARRYOVER`

- `SESSION_ORCHESTRATOR_TOOLS_DENIED`
- `ATTESTATION_MISSING`
- `ATTESTATION_HASH_MISMATCH`

Transcript detector does **not** parse Pi jsonl in workflow code. Tests inject tainted restore and expect `SESSION_TRANSCRIPT_CARRYOVER`. Context pack stub contains artifacts/handoff hashes, never prior-role transcript (R5). US-0139 owns the real pack.

Orchestrator mutation **before ToolBroker** (US-0137): spawn-time allowlist check. If `role_id === "orchestrator"` and tools contain write/bash/edit/`itsm_*` mutation names → `SESSION_ORCHESTRATOR_TOOLS_DENIED`. Actual phase writes by the scheduler → `AUTO_ORCHESTRATOR_PHASE_EXECUTION`.

### 8. Orchestrator scheduling-only (DQ7 / AC-6) — LOCKED

- **Winner**: **pure TypeScript scheduler** (no orchestrator Pi session in v1). This story ships the spawn-time gate inside `role-runtime` (`assertOrchestratorSchedulingOnly`). US-0140 owns the lifecycle loop that consumes SessionSupervisor. Do **not** create `runtime-core` this story.
- If a future orchestrator-role Pi session exists: `customTools=[]`, `tools=[]`, `noTools: "builtin"` held — **zero** custom tools (not `itsm_ping`).
- Proof without PolicyEngine: contract tests assert orchestrator spawn tool allowlist empty + attempting `write`/`bash`/`edit`/`itsm_*` mutation names fails `SESSION_ORCHESTRATOR_TOOLS_DENIED`; scheduler/gate module must not import Pi.

### 9. Critic / review + crash (DQ8 / DQ9 / AC-1 / AC-7) — LOCKED

- SessionSupervisor spawns a **fresh** session for sovereign-critic and role-behavior reviews. Review never substitutes the producer role.
- Attestation `parent_phase_session_id` = producer `kernel_session_id`; `fresh: true`; distinct `kernel_session_id`. Isolation/proof `role` for sovereign-critic remains `tech-lead`.
- `model_id` from DEC-0135 critic overlay / pin; same slug → `CROSS_MODEL_DEGRADED_MODE` (compose US-0104 v2). This story does **not** author critic lens content (US-0144).
- Dispose producer only after end attestation; critic must not `steer` the producer session.

Crash / dispose (session facts only; US-0140 reconstructs next phase):

1. Track live handles (`kernel_session_id` → KernelSession).
2. On restart / crash fixture: any handle without an `end` attestation is an **orphan** → `abort` + `dispose` + drop registry row; do not `continueRecent` / restore `entries`.
3. `end` attestation present **and** kit proof valid ⇒ complete; missing end / process death ⇒ crashed (not complete). Supervisor does not flip backlog Status.
4. Next spawn is always `createSession` (fresh).
5. `dispose()` must be called in tests; after dispose, `sessionId` must not be reused for a later phase.
