# DEC-0148: Stable local control protocol and recoverable daemon

- Date: 2026-09-17
- Status: Accepted
- Story: `US-0148`
- Research: `R-0148` (DQ1–DQ10 LOCKED; `/research` auto-20260917-us0148)

## Context

Operators and future client authors need a versioned local control boundary so CLI/TUI can attach to long-running work across disconnects and restarts without duplicating workflow rules in a transport layer. US-0146 delivered in-process `OperatorSession` reconnect; this story **supersedes production attach** with cross-process daemon clients while preserving US-0146 contract semantics via `InProcessTransport` doubles. SQLite operational state (`runs/store`) and `crashResume()` exist but are not daemon-orchestrated today. Masterplan §29.3 / §30 / Phase 8 JSON-RPC applies.

R-0148 locked DQ1–DQ10 and recommended **A1 (A\*)**. `decision_gate=false`. This DEC accepts A1 and pins transport, packages, event log, transport migration, versioning, restart policy, local auth, redaction, concurrency roles, twelve `test_us0148_*` contract markers, and operator doc path.

## Decision

1. **Approach A1** — add **`@its-magic/protocol`** (`standalone/packages/protocol`) with versioned `RuntimeCommand` / `RuntimeEvent` unions, JSON Schema (or equivalent checked-in artifacts), `protocol_version`, `redactEventPayload()`, and a thin **`protocol-client`** consumed from **`runtime-core/src/daemon-client/`**. Add **`@its-magic/daemon`** (`standalone/apps/daemon`) as loopback-only host owning **one** in-process `WorkflowEngine` + existing operator facades (`OperatorCommandFacade`, `OperatorObservabilityService`, `OperatorPrompts`) — **no workflow rules** in daemon beyond delegation. Expose **JSON-RPC 2.0** on **`127.0.0.1`/`::1` only** (default-deny `0.0.0.0`) and **WebSocket** ordered events at **`/v1/events`** on the same listener. Persist listen metadata **`.its-magic/daemon/listen.json`** and ephemeral bearer **`.its-magic/daemon/client.token`** (0600-class). CLI/TUI use **`OperatorTransport`** with **`DaemonTransport`** default when daemon reachable; **`InProcessTransport`** retained for US-0146 contract doubles only — production attach MUST NOT silently fall back when daemon required (AC-3). Reject Pi on wire, remote-first bind, workflow logic in daemon, `CommandRouter`/`GateEngine` rewrite, distributed workers v1, shipping deferred rich clients, npm-publish, git push, `.env` reads.
2. **Transport (DQ1)** — JSON-RPC methods: `daemon.ping`, `daemon.hello`, `run.start`, `run.attach`, `command.submit`, `approval.respond`, `run.cancel`, `status.snapshot`. Errors: JSON-RPC codes + `PROTOCOL_*` / `DAEMON_*` families. Port from listen file; Windows/Linux loopback HTTP v1 (optional future UDS additive).
3. **Packages (DQ2)** — `protocol` has no cli/tui imports; `daemon` depends on `runtime-core` + `protocol` only. Checked-in schema sources required — no orphan generated-only artifacts.
4. **Event log (DQ3)** — per-run SQLite append-only table (`run_id`, monotonic `seq`); subscribe with `after_seq`; replay then live; gap → `EVENT_SEQ_GAP`; lag > `DAEMON_EVENT_LAG_MAX` → bounded summary events + `evidence_ref` (compose US-0146 log caps). Hooks on existing workflow/observability emitters — no duplicate emitters.
5. **CLI/TUI migration (DQ4)** — `OperatorTransport` interface `{ submitCommand, subscribeEvents, attachRun, cancel, respondApproval }`; US-0146 `test_us0146_*` green via in-process path; new cross-process coverage in `test_us0148_*` only. Command vocabulary unchanged.
6. **Versioning (DQ5)** — `daemon.hello` negotiates `protocol_version`, `capabilities`, `supported_protocol_range`; mismatch → `PROTOCOL_VERSION_MISMATCH` fail-closed; unsupported method → `-32601` + `PROTOCOL_COMMAND_UNSUPPORTED`. Test-only `force_compat=1` allowed in contract doubles.
7. **Restart (DQ6)** — daemon startup runs `crashResume(repo, store)` then `reconcileOperationalLedger()` (pins: compose `RunsStore` + `handoffs/resume_brief.md` / sprint pointers); orphan child PIDs and stale attach tokens TTL-cleaned; resume work only via **fresh** `SessionSupervisor` sessions (US-0136); incomplete reconcile → `RECONCILE_INCOMPLETE` fail-closed; daemon never flips backlog Status.
8. **Local security (DQ7)** — bearer token required on RPC and WebSocket; roles `controller` vs `observer` in attach handshake; **one controller** lock (`DAEMON_CONTROLLER_BUSY`); remote bind only when `ITS_MAGIC_DAEMON_REMOTE=1` + explicit allowlist (default off).
9. **Redaction (DQ8)** — `redactEventPayload()` on every outbound event and RPC result serializer; golden vectors shared where applicable with US-0135 / US-0146 rules.
10. **Concurrency (DQ9)** — one controller + N observers; approvals to first controller or `APPROVAL_NO_CONTROLLER`; cancel maps to existing stop-matrix / `OperatorSession.cancel` delegation; audit `client_id` + `client_kind` (`cli`|`tui`|`test`).
11. **Tests + docs (DQ10)** — twelve `standalone/tests/contract/us0148.contract.test.ts` markers (`test_us0148_*`); ephemeral daemon on port 0; no live remote network. Operator doc **`docs/engineering/operator/daemon-protocol.md`** for AC-8 deferred-client boundary. Kit `files` omit root `standalone/` (no template mirror unless install story later requires — default omit).
12. **Compose-only** — US-0133..US-0147 DONE (US-0146 clients migrate; US-0143 scheduling IN; US-0140 commands IN). US-0145 delivery OUT of daemon. BUG-* compose only; BUG-0022 not drained. No restore `.opencode/commands/auto.md`. No kit `cli.json` / plugin `tui.json`.
