# DEC-0146: CLI, TUI, and operator facades (sibling clients; runtime-core operator module)

- Date: 2026-09-17
- Status: Accepted

## Context

Operators need a coherent local `itsm` CLI and replaceable TUI backed by runtime services. `@its-magic/cli` is a Phase-0 stub; no `@its-magic/tui` exists. US-0140 `CommandRouter`, US-0143 `/auto`/`/quick` scheduling, US-0141 app health, US-0142 browser evidence, US-0139 index, US-0080 token-cost evidence, and US-0144 read-only sovereign fields are available to compose — not rewrite.

R-0143 locked DQ1–DQ10 and recommended **A1 (A\*)**. `decision_gate=false`. This DEC accepts A1 and pins architecture-owned module paths, prompt env/flags, log caps, and nine `test_us0146_*` contract markers.

## Decision

1. **Approach A1** — sibling `@its-magic/cli` (`standalone/apps/cli`) and new `@its-magic/tui` (`standalone/apps/tui`) as **thin clients** of nested `standalone/packages/runtime-core/src/operator/` exporting `OperatorCommandFacade` (delegates to existing `CommandRouter` + `WorkflowEngine` without forking routing tables) and `OperatorObservabilityService` (status, timeline, metrics snapshots). Reject nesting apps inside runtime-core, a third observability package in v1, fat CLI owning `WorkflowEngine`, OpenCode plugin as `itsm`, US-0148 daemon protocol in v1, and graphical clients.
2. **Pi boundary** — US-0135 `dispatchItsmCommand` + `pi-kernel` `AuthRuntimeAdapter` **only** on `auth`/`models` argv paths. No Pi imports on workflow, status, timeline, TUI panel, or observability paths.
3. **Command surface (AC-1)** — single facade maps AC-1 vocabulary: lifecycle tokens → `PROGRAMMATIC_COMMANDS` via `CommandRouter`; `auto`/`quick` → US-0143 `RouteScheduled`; `ask`, `status`, `resume`, `index`, `app`, `browser` → dedicated facade methods; `auth`/`models` → `dispatchItsmCommand` unchanged. Interactive REPL parses the same tokens as argv. Kit installer `its-magic` bin remains US-0147 OUT.
4. **Observability (AC-2..AC-5)** — `buildStatusSnapshot()`, `buildRunTimeline()`, and `buildMetricsSnapshot()` are read-mostly DTO composers over `RunsStore`, repo pointers, US-0141 health, US-0139 index, US-0142 evidence APIs, US-0080 latest run evidence (no second ledger writer), and US-0144 sovereign fields when `SOVEREIGN_RUNTIME=1` (omitted when disabled). Metrics conflicts surface `metrics_stale` / `evidence_missing`, not silent overwrite.
5. **TUI (AC-4)** — replaceable terminal client using **readline + ANSI regions** (no OpenCode plugin host; no Pi TUI SDK on workflow paths). Panels consume typed DTOs only; **no** `CommandRouter` / `GateEngine` / drain imports in `@its-magic/tui` workflow paths.
6. **Prompts (AC-6)** — shared `OperatorPrompts` in `operator/` used by CLI and TUI: interactive keyed choices, min width 40 cols, UTF-8 on Windows and Linux; non-interactive requires `ITS_MAGIC_APPROVE=…` and architecture-pinned `--yes`/`--no` only where safe — otherwise `OPERATOR_INPUT_REQUIRED`.
7. **Logs (AC-7)** — bounded views default **200 lines** / **32 KiB** visible with `{truncated, total_bytes, evidence_path}` footer; reuse US-0141 ring helpers when present; streams use backpressure drop + summary.
8. **Session (AC-8)** — v1 **in-process** `OperatorSession`: attach/reconnect re-binds listeners and refreshes snapshots in the same Node process; cancel maps to existing stop-matrix / workflow cancel tokens — **not** US-0148 socket protocol.
9. **Tests** — nine hermetic `standalone/tests/contract` markers (IDs below). Kit `files` omit `standalone/`. No `.opencode/commands/auto.md` restore. No kit `cli.json` or plugin `its-magic-auto/tui.json`.
10. **Compose-only boundaries** — US-0140..US-0144 DONE (do not reopen). US-0145 / US-0147 / US-0148 bodies OUT. BUG-* compose only. `WorkflowEngine`, `CommandRouter`, and `GateEngine` are not rewritten.
