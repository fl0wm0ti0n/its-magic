## Context

The published kit (`package.json` name `its-magic`, `files` = template/installer/scripts/bin) is not a TypeScript agent runtime. US-0133 must bootstrap a **separate** standalone workspace and prove Pi sits behind an owned `AgentKernel` with custom-tool-only production sessions and default resource isolation. Pi has **no built-in OS sandbox** (pi.dev/security). Phase 0 go/no-go for this story is kernel items **1, 2, 3, 5 only**.

R-0121 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1, closes architecture deferred items (AgentKernel TypeScript surface, fake-model seam, owned events, evidence path, unpublished workspace name), and closes research-critic informational NBs (`us0133rsc-*`).

### 2. Hosting + kit publish boundary (DQ1 / AC-1)

- Path: **`standalone/`** inside this git repo. Independent npm workspaces root (`standalone/package.json`). **Do not** add `standalone/` to kit root `package.json` `workspaces` (kit is not a workspace root).
- Kit `files` **must omit** `standalone/`. Guard: contract test + `guard_installer_publish.py` fail-closed if `standalone` appears in kit `files` or published tarball inventory.
- Workspace `"name"` is an unpublished code name (`private: true`). Suggested `@its-magic/standalone` / bin `itsm` — **AC-6: do not lock public branding**; do **not** reuse npm name `its-magic`.
- **US-0134 locate path (document only, do not implement)**: walk up from cwd / `standalone/` to the kit repo root that contains `docs/product/backlog.md` + shipped Python validators.

### 3. Minimal inventory (DQ4)

Ship now:

- `standalone/apps/cli` **stub** only (code-name bin; no workflow / no ToolBroker)

### 4. AgentKernel surface (DQ2 / AC-2) — LOCKED

Owned types live in `packages/pi-kernel`. Workflow / `apps/cli` import **only** these types — never Pi modules.

```ts
type IsolationMode = "off" | "trusted";

interface KernelRuntimeInfo {
  sessionId: string;
  piCodingAgentVersion: string; // exact installed
  piAiVersion: string;
  isolationMode: IsolationMode;
  builtinTools: "disabled";
}

type KernelEvent =
  | { type: "agent_start"; sessionId: string }
  | { type: "tool_execution_start"; sessionId: string; toolName: string }
  | { type: "tool_execution_end"; sessionId: string; toolName: string }
  | { type: "agent_end"; sessionId: string };

interface KernelSession {
  readonly sessionId: string;
  run(text: string): Promise<void>;      // session.prompt
  steer(text: string): Promise<void>;    // session.steer
  abort(): Promise<void>;                // session.abort
  dispose(): void;                       // session.dispose
  getRuntimeInfo(): KernelRuntimeInfo;
  subscribe(handler: (e: KernelEvent) => void): () => void;
}

interface AgentKernel {
  createSession(options?: KernelCreateSessionOptions): Promise<KernelSession>;
}
```

SDK map (inside `pi-kernel` only): `createSession` → `createAgentSession`; `run` → `session.prompt`; `steer` → `session.steer`; extra Pi events (`message_*`, `turn_*`, `queue_update`) may be ignored.

Import boundary: Biome `noRestrictedImports` on every workspace package except `pi-kernel` **plus** fail-closed grep for `@earendil-works/pi-` outside `standalone/packages/pi-kernel/**`.

### 5. Production isolation + tools (DQ5 / AC-3 / AC-4)

Production factory **must** combine:

1. `noTools: "builtin"`
2. `customTools` = owned spike tool(s) only; `tools` allowlist **includes each custom name**
3. Injected `resourceLoader`: `DefaultResourceLoader` with empty overrides (`agentsFilesOverride` / `skillsOverride` / `promptsOverride` yield empty; no `additionalExtensionPaths` / `extensionFactories`); loader `cwd`/`agentDir` = runtime-owned empty dir (not `~/.pi/agent`, not the target project)
4. `SessionManager.inMemory()` for tests

Product flag `PI_COMPAT_RESOURCES` default **`off`**. `trusted` is an explicit option recorded on `KernelRuntimeInfo.isolationMode`. **US-0133 production factory still uses the empty loader even when `trusted`** — loading project `.pi/extensions` / treating `AGENTS.md` as enforcement is **US-0137**. Trusted must never enable third-party mutation tools.

Placeholder spike tool: **`itsm_ping`** only. Full ToolBroker catalog = **US-0137**.

**No OS-sandbox claim** (D8). Docs cite pi.dev/security.
