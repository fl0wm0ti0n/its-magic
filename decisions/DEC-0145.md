# DEC-0145: Parallel development, release/deploy, self-healing, and closure

- Date: 2026-09-17
- Status: Accepted
- Story: `US-0145`
- Research: `R-0145` (DQ1–DQ10 LOCKED; `/research` auto-20260917-us0146)

## Context

Operators need optional parallel DEV candidates and typed release/deploy with bounded post-deploy repair so the runtime can arbitrate verified implementations, publish safely, heal remediable failures, and hand final status only to the exclusive closure phase. Kit Python libs `scripts/parallel_dev_arbiter.py` (US-0108) and `scripts/self_healing_deploy_lib.py` (US-0109) exist but are not wired into `@its-magic/runtime-core` WorkflowEngine. US-0140 owns `releaseCannotMarkDone` / `applyClosure`; US-0143 drain is IN and must not be rewritten; US-0146 CLI/TUI observe/trigger only; US-0147 install/bootstrap IN (compose-only).

R-0145 locked DQ1–DQ10 and recommended **A1 (A\*)**. `decision_gate=false`. This DEC accepts A1 and pins delivery module paths, bridge ops, target kinds, ledger paths, gate compose rules, reason codes, and twelve `test_us0145_*` contract markers.

## Decision

1. **Approach A1** — add nested **`standalone/packages/runtime-core/src/workflow/delivery/`** with **`ParallelDevCoordinator`** (optional post-execute fork) and **`ReleaseDeployPipeline`** (typed targets + post-deploy healing) as thin TS orchestrators over closed **`KernelBridge.runDeliveryOperation()`** (mirror `runSovereignOperation`) backed by **`scripts/delivery_runtime_bridge.py`** dispatching to existing **`parallel_dev_arbiter.py`** and **`self_healing_deploy_lib.py`** (no TS ports of git/worktree/healing). Default-off: `SOVEREIGN_PARALLEL_DEV=0` and `AUTO_SOVEREIGN_SELF_HEALING_DEPLOY=0` preserve byte-identical paths when disabled.
2. **WorkflowEngine hooks (DQ1)** — `ParallelDevCoordinator` invoked only when `lookupParallelDev(config)` true (`SOVEREIGN_PARALLEL_DEV=1` + scratchpad keys per DEC-0108). Hook **after execute phase PASS** (before independent QA merge path): spawn N isolated DEV sessions via bridge `parallel_dev_spawn`; main tree read-only for producer edits until QA arbiter merge. US-0143 `/auto`/`/quick` drain unchanged; `parallel_dev_requested` metadata no-ops when disabled.
3. **Worktrees (DQ2)** — bridge ops `parallel_dev_create_worktrees`, `parallel_dev_list_active`, `parallel_dev_cleanup_orphans`, `parallel_dev_merge_winner` compose DEC-0108; roots `.its-magic/worktrees/<run_id>/` (gitignored); PolicyEngine allowlist extended additively; fail-closed `PARALLEL_DEV_WORKTREE_CREATE_FAILED` when git missing; `handoffs/parallel_dev_pick.json` v1 schema held.
4. **QA arbiter (DQ3)** — fresh **`role-runtime`** session `phase_id=qa-arbiter` consumes candidate evidence packages `{candidate_id, worktree_path, test_report_refs[], diff_stat_ref, token_cost_ref, model_ids[]}`; outcomes `winner_selected` → merge; `reject_all` → `PARALLEL_DEV_SELECTION_NO_PASS`; `merge_conflict` → evidence, no DONE flip. Arbiter `session_id` ≠ any candidate DEV session (compose US-0136).
5. **Resource guards (DQ4)** — **`DeliveryResourceGuard`** reads scratchpad caps (DEC-0108 + DEC-0109), US-0080 token/cost totals, and runtime counters (worktrees, concurrent tests, browser slots US-0142) with fail-closed `PARALLEL_DEV_RESOURCE_CAP_EXHAUSTED`, `DELIVERY_WALL_CLOCK_EXCEEDED`, `DELIVERY_TOKEN_BUDGET_EXHAUSTED`, `DELIVERY_CONCURRENT_TEST_CAP`. `ConfigView` lookups only in v1.
6. **ReleaseTarget registry (DQ5)** — TS **`ReleaseTargetKind`**: `git_github`, `npm`, `ssh_command`, `docker`, `custom_command`; **`ReleaseTargetAdapter`** `{kind, describe(), dryRun(ctx), apply(ctx), verify(ctx)}`; **`DeployTargetResult`** appended to **`handoffs/deploy_results/deploy_results.jsonl`** (architecture-pinned). Idempotency `target_run_key = hash(orchestrator_run_id, sprint_id, target_id, attempt)`. Secrets via config secrets API (env key names only — **no `.env` file read**).
7. **Gates (DQ6)** — extend **`ReleaseGateInput`** additively with optional `deploy_targets_pass`, `approval_granted`, `target_policy_ok` evaluated inside `createGateEngine().evaluate()` **after** existing five steps — **without** amending **`RELEASE_GATE_ORDER`** array literal. Release evidence envelope gains optional `deploy_results_ref`, `approval_ref`.
8. **Post-deploy healing (DQ7)** — **`ReleaseDeployPipeline.runPostDeployHealing()`** after target `apply` PASS composes bridge `deploy_smoke_probe`, `deploy_healing_retry` with `AUTO_SOVEREIGN_DEPLOY_RETRY_MAX`; smoke evidence + US-0142 browser read APIs when configured; bounded fresh DEV repair slot (BUG-0006) → rebuild artifacts → re-apply targets (no full execute restart).
9. **Deferral + truthfulness (DQ8)** — exhausted healing → US-0107 `append_deferral(work_item_kind=deploy)` with `DEPLOY_DEFERRED` / `DEPLOY_HEALING_DEFERRED`; **`writeReleaseEvidence`** fail-closed when any required target not OK; no `RELEASE_PASS` in `handoffs/releases/*` or `release_queue.md` while deferred; US-0146 status shows `deploy_state=deferred`.
10. **Closure boundary (DQ9)** — enforce **`releaseCannotMarkDone()`** on all release-phase writers; **`applyClosure()`** sole DONE authority; contract tests mirror `us0140` forbidding `status_written: DONE` from release helpers; successful release returns `{ marked_done: false, deploy_results_ref?, release_run_id }` then separate closure phase only.
11. **Tests** — twelve hermetic `standalone/tests/contract/us0145.contract.test.ts` (`node:test`) + fake git/target doubles; optional pytest bridge self-tests; no live npm publish, git push, or paid network.
12. **Compose-only** — US-0140..US-0147 DONE (US-0143 drain, US-0146 observe, US-0140 closure). US-0148 OUT. BUG-* compose only; BUG-0022 not drained. No restore `.opencode/commands/auto.md`. No kit `cli.json` / plugin `tui.json`. Kit `files` omit `standalone/`.
