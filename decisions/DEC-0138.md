## Context

Standalone runtime still resolves delivery/token/work-kind/phase/model/autonomy/stop/retry/browser/dev-env/remote/security/sovereign settings from kit Python + scratchpad comments. R9 requires code-parsed TypeScript. Existing repos must keep identity without forced migration (AC-3 / AC-6 / DEC-0039). Credentials stay in US-0135. PolicyEngine already owns thin enums (DEC-0137); this story supplies typed flags, not new decision tables.

R-0130 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1 and closes architecture-owned pins: package split, Zod schema + versioning, same `.its-magic/` JSONC files as US-0131, public 5-layer ladder mapped onto kit 7-layer, CLI argv/env names, TS `LegacyScratchpadAdapter`, secret names/handles only, fail-closed `CONFIG_*`, US-0119 expansion + R10, injection-only compose, and twelve `test_us0138_*` markers. It also closes research-critic informational NBs (`us0138rsc-*`).

### 2. Package + import boundary (DQ1 / AC-1)

- Path: **`standalone/packages/config`**. npm name `@its-magic/config`, `private: true`, `version: 0.0.0`, `type: module`, `engines.node >=22.19.0`, export `./src/index.ts`. Workspaces glob `packages/*` already covers it. **Execute owns the package files** — this DEC does not create them.
- **No Pi imports.** `package.json` must not depend on `@earendil-works/pi-*`. Extend US-0133..0137 grep to deny Pi inside `packages/config`. Type-only imports from `@its-magic/policy-engine` / `@its-magic/auth-models` / `@its-magic/role-runtime` are allowed for enum/flag types. Do **not** add a Biome override.
- Surface: `resolveRuntimeConfig(repoRoot, options) -> { config: RuntimeConfig, provenance: Record<string, Provenance>, diagnostics: string[], ok, fatal_code? }` plus `LegacyScratchpadAdapter.parse/map`. Consumers receive the **resolved object**, not loader internals.
- Injection only: CLI/workflow (US-0140 later) and current spawn sites pass typed flags into PolicyEngine (`autonomy` / `permission_mode` / `security_class` / `isolation_profile`), ModelRouter (`tokenProfile` name + thinking orthogonality — **not** credentials), SessionSupervisor / RoleCatalog (phase/role `AUTO_ROLE_*` keys). Those packages **do not** import config loaders.
- Do not amend isolation loader internals, `noTools: "builtin"`, KernelBridge, auth-models credential store, RoleCatalog internals, or PolicyEngine decision tables.
- Kit `files` continues to omit `standalone/` (DEC-0120). Do **not** stub `runtime-core` this story.

### 3. Schema language + versioning (DQ2 / AC-1 / AC-5)

- Owned TypeScript types + **Zod** as the parse gate (`z.parse` / mapped `safeParse` → `CONFIG_*`). JSON Schema (`z.toJSONSchema(schema, { target: "draft-2020-12" })`) is a **derived** operator/docs artifact, not a second writer.
- `schema_version` required int; **v1 supported**. Unknown/unsupported version → `CONFIG_SCHEMA_UNSUPPORTED`.
- File format: **JSONC** (`//` and `/* */`). Reject YAML SOT. Reject executable `.js`/`.ts` loaders.
- Allowed top-level keys: `schema_version`, `shared`, `host_overlays` (compose kit `_ALLOWED_TOP_KEYS`). Strict unknown **top-level** keys → `CONFIG_INVALID`.
- Nested `shared` unknown keys: diagnostic `CONFIG_UNKNOWN_KEY` (non-fatal unless `CONFIG_STRICT=1`; **default-off**) so existing repos keep identity (AC-6).

### 5. CLI one-run pins (DQ4 / R2) — LOCKED

Layer 1 is **one** layer. Argv and env are peers; if both set and **disagree** for the same key → `CONFIG_INVALID` (conflict, fail-closed).

| Flag | Env | Value |
|---|---|---|
| `--delivery-mode` | `ITSM_RUNTIME_DELIVERY_MODE` | `standard` \| `ultra_lean` \| `mega_quick` |
| `--token-profile` | `ITSM_RUNTIME_TOKEN_PROFILE` | `lean` \| `balanced` \| `full` |
| `--autonomy-preset` | `ITSM_RUNTIME_AUTONOMY_PRESET` | `none` \| `balanced` \| `full` |
| `--work-kind` | `ITSM_RUNTIME_WORK_KIND` | `0` \| `1` (maps `WORK_KIND_ROUTING`) |
| `--runtime-override KEY=VAL` | `ITSM_RUNTIME_<KEY>` | `KEY` matches `^[A-Z][A-Z0-9_]*$` |
| `--config-strict` | `ITSM_RUNTIME_CONFIG_STRICT` | `0` \| `1` (default 0) |

Axes stay orthogonal (D1 / §15): a layer that sets one of `DELIVERY_MODE` / `TOKEN_PROFILE` / `AUTONOMY_PRESET` / `WORK_KIND_ROUTING` must not coerce the others.

### 6. Precedence + provenance (DQ4 / AC-2) — LOCKED

Public ladder (highest wins, **per key**): CLI one-run > local project > shared project > legacy scratchpad > framework defaults.

Map onto US-0131 7-layer interleave **without replacing the Python resolver**:

| Public | Kit analog labels |
|---|---|
| 1 CLI | reserved CLI/env (now real on standalone) |
| 2 local | `kit_local` |
| 3 shared | `kit_baseline` |
| 4 legacy | `cursor_local` then `cursor_baseline` (adapter; kit local still shadows cursor local) |
| 5 defaults | `kit_example` then `code_defaults` |

Provenance per resolved key: `{ layer, label, path?, source_key }`. Emit `CONFIG_KEY_SHADOWED` when kit local ≠ cursor local (non-fatal unless `CONFIG_STRICT=1`). Security-hard disagreements that would **weaken** a higher layer → fatal `CONFIG_UNSAFE_RELAXATION` (not a shadow diagnostic).

### 7. LegacyScratchpadAdapter (DQ5 / AC-3) — LOCKED

- TypeScript reimplementation of parse/validate/map (KEY=VAL comments; DEC-0055 local > baseline > example **inside** the adapter). **Do not spawn** Python `parse_scratchpad_*`. **Do not rewrite** `host_runtime_config_lib.py`.
- Absent legacy files → valid empty mapping (AC-3 / AC-6). Malformed **present** file → `CONFIG_LEGACY_INVALID` fail-closed (not silent skip).
- Unknown scratchpad keys: keep in opaque `compat` bag + `CONFIG_UNKNOWN_KEY` diagnostic; do not fail existing-repo identity unless `CONFIG_STRICT=1`. **Pinned default: non-fatal.**
- Migration diagnostics are **actionable and non-blocking**: `CONFIG_MIGRATION_HINT` listing keys that would live in `.its-magic/config.json` if the operator migrates. **No forced write.**
- **DEC-0039**: never overwrite `.its-magic/config.local.json` or `.cursor/scratchpad.local.md`.
- `MODEL_*` / `MODEL_TIER_*` in scratchpad: **ignore** as host-catalog keys (US-0132/0135 boundary). Standalone model **names** come from typed `model` group referencing catalog handles, not vendor secrets.

### 8. Secret boundary (DQ6 / AC-4) — LOCKED

- Reject secret-**shaped values** in shared **and** local project files and in legacy mapped values. Port kit `_SECRET_PATTERNS`: `api_key`/`secret`/`password`/`token` assignments, `sk-`/`ghp_`/`xox` prefixes, PEM private keys, `Bearer …`.
- Allow **names/handles only**: `secret_name` / `credential_handle` matching `^[A-Za-z][A-Za-z0-9_.-]*$`. Resolve values inside US-0135 owned store / execution layer — **this package never reads credentials**.
- **Never** read `.env`. **Never** log provider tokens. Compose US-0135 `redactAudit` / `redactSecretShaped` on diagnostics if a reject fires (code + key name, not value).
- Standalone fatal token: **`CONFIG_SECRET_REJECTED`**. Analog map `HOST_CONFIG_SECRET_REJECTED` → `CONFIG_SECRET_REJECTED`. Do **not** reuse kit Python codes as standalone fatal tokens.

### 9. Autonomy / security_hard (DQ7 / AC-5) — LOCKED

Port US-0119: expand `AUTONOMY_PRESET=none|balanced|full` to the twelve per-feature flags **before** execution; explicit per-flag > preset > defaults (DEC-0119 R5). Flags (compose DEC-0119 §7, do not invent new consumer semantics): `INTAKE_AUTONOMY_MODE`, `INTAKE_MINIMAL_PACK`, `INTAKE_ASSUME_STACK_CONTEXT`, `WORK_KIND_AUTO_ACCEPT`, `CROSS_MODEL_REWORK_EXHAUSTED_POLICY`, `CROSS_MODEL_SKIP_PHASES`, `RESUME_BRIEF_AUTO_REFRESH`, `RUNTIME_PROOF_KIND`, `GOAL_CONVERGENCE_INTERVAL`, `SOVEREIGN_DRAIN_AUTO_ACCEPT`, `RELEASE_PUBLISH_AUTO_CONFIRM`, `AUTONOMY_STOP_POLICY`.

**PolicyEngine thin-enum mapping (pinned):**

| Config | PolicyEngine |
|---|---|
| `AUTONOMY_PRESET=none` | `Autonomy="supervised"` (empty 12-flag expansion) |
| `AUTONOMY_PRESET=balanced` | `Autonomy="autonomous"` + 8 of 12 flags per DEC-0119 |
| `AUTONOMY_PRESET=full` | `Autonomy="autonomous"` + all 12 flags per DEC-0119 |
| `PERMISSION_MODE=interactive` | `PermissionMode="ask-on-write"` |
| `PERMISSION_MODE=auto` | `PermissionMode="default-deny"` |

`SecurityClass="security_hard"` and matrix rows classified `security_hard` **cannot** be marked `autonomy_resolvable` by any layer or by the preset (R10 / US-0119 / US-0137). Attempt → `CONFIG_UNSAFE_RELAXATION`. Models never decide relaxability (§14.6). `AUTONOMY_STOP_POLICY` remains `block|auto_repair_then_block|auto_repair_then_skip` and cannot demote hard gates. IsolationProfile passthrough (`trusted-local` \| `isolated-development` \| `untrusted-repository`) is Layer A only; Layer B backends = US-0141 OUT.
