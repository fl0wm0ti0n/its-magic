## Context

Standalone TypeScript runtime can route 16 programmatic commands through CommandRouter's 7-step producer path and run a bounded execute↔QA loop, but `/auto` and `/quick` still return fail-closed `WORKFLOW_ROUTE_DEFERRED` (`implemented: false`). Operators need one command to resolve target work, work-kind, delivery mode, phase plan, role/model/policy, evidence, critic *hooks*, bounded repair, release→closure→refresh, and optional next-item drain **in runtime state**, without letting models bypass hard stops.

R-0141 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1 and closes architecture-owned pins: in-place CommandRouter lift (no sibling package, no Pi), `RouteScheduled` vs 7-step, independent axes, L8 TS adapter, compressed canonical node sets, WorkflowEngine-owned §14.4 drain, YAML stop-matrix consume + AC-6 additive `security_hard` codes, dual-write ledger, twelve `test_us0143_*` markers, and sprint seeds. It also closes research-critic informational NBs (`us0143rsc-*`).

### 2. Package + lift (DQ1 / DQ2 / AC-1)

- Path: existing **`standalone/packages/runtime-core`** (`@its-magic/runtime-core`). Nested helper **`src/workflow/delivery-router.ts`** (L8 + independent axes + compressed plans) used by CommandRouter and WorkflowEngine. **No** sibling `packages/auto-scheduler`. **No Pi imports.** Do not add a Biome override. Kit `files` omit `standalone/` (DEC-0120). Do not add standalone to kit workspaces. **Execute owns the code files** — this DEC does not create them.
- CommandRouter **implements** `/auto` and `/quick`. It returns **`RouteScheduled`** (`ok: true`, `implemented: true`, `plan`, `axes`). It does **not** run the 7-step producer path for the scheduler command itself (scheduler is not a canonical phase). `WorkflowEngine.runAuto` / `runQuick` then walks the resolved plan via existing `route(phase)` 7-step. Programmatic 16-command path **unamended**.
- **`SCHEDULER_COMMANDS = ["/auto", "/quick"]`**. Fate of `DEFERRED_COMMANDS`: **empty after this story** (`[] as const`) or removed. Keep `WORKFLOW_ROUTE_DEFERRED` in `stop-matrix/codes.ts` for unknown future stubs; `/auto`/`/quick` **must not** return it.
- `listCommands()` still lists `/auto` and `/quick` as implemented scheduler commands.
- `RouteResult = RouteOk | RouteDeferred | RouteScheduled`.
- Execute **must compose-amend** `test_us0140_command_coverage` so it no longer expects deferred `/auto`/`/quick` (US-0140 ACs stay DONE; contract evolution, not a reopen). Additive `test_us0143_*` own the new behavior.
- **Reject** rewriting GateEngine `RELEASE_GATE_ORDER`. **Reject** keeping deferred as the happy path.

`RouteScheduled` fields **LOCKED**:

- `ok: true`
- `implemented: true`
- `command: "/auto" | "/quick"`
- `plan: CanonicalPhase[]`

- `host_scheduling_only: true`
- `conflict_code?: "WORK_KIND_DELIVERY_MODE_CONFLICT"` (explicit wins; conflict surfaced)

### 6. Drain loop owner + caps (DQ6 / AC-5)

- New methods: `runAuto(input)`, `runQuick(input)`. Existing `runExecuteQaLoop` / `runCommand` / `evaluateRelease` stay; `runAuto` reuses `runExecuteQaLoop` for execute↔qa and `evaluateRelease` before release.

- Operator authority: pause, skip, approval gates, and `AUTONOMY_PRESET=none` remain operator-visible and non-bypassable.
