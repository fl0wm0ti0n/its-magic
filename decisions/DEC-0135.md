## Context

US-0133 shipped `AgentKernel` with a fake-model CI inject seam. US-0134 shipped `KernelBridge`. The standalone runtime still has no owned credential store, no ModelRouter, and no `itsm auth` / `models` commands. US-0135 must authenticate providers (Codex OAuth, API-key, Chinese built-ins, local/custom via owned `models.json`) and resolve per-role/phase models through a 6-step router with observable provenance, independent thinking, and critic pinning — without exposing tokens to agents, repos, or audit.

R-0127 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1 and closes architecture-owned items: AuthService/ModelRouter/AuthRuntimeAdapter TypeScript surfaces, owned store path + 0600-class, 6-step precedence + provenance fields, thinking clamp (not fail-closed), critic degraded reuse of `CROSS_MODEL_DEGRADED_MODE`, CLI inventory, and the ten `test_us0135_*` markers. It also closes research-critic informational NBs (`us0135rsc-*`).

## Decision

### 1. Approach A1 — `auth-models` + AuthRuntimeAdapter + owned OS store (LOCKED)

| Option | Summary | Verdict |
|--------|---------|---------|
| **A1** | `standalone/packages/auth-models` (AuthService + ModelRouter + thin catalog + CLI handlers; **no Pi imports**); pi-kernel **AuthRuntimeAdapter** wrapping `ModelRuntime.create({ authPath, modelsPath })` / `login` / `checkAuth` / `registerProvider`; owned OS credential dir; 6-step router + provenance; thinking inject independent of slug/`TOKEN_PROFILE`; critic pin + `CROSS_MODEL_DEGRADED_MODE`; `itsm auth` / `models list` / `models test`; fake-model CI default **held**; empty loader / `noTools` / KernelBridge **unamended** | **Accepted** — AC-1..AC-7; D1–D10 |
| A2 | Stable store = `~/.pi/agent/auth.json` | **Rejected** — D1 spike-only |
| A3 | Credentials in project / `.env` | **Rejected** — AC-1 / D7 / §26.4 |
| A4 | Workflow/CLI import `@earendil-works/pi-*` | **Rejected** — R1 / DEC-0133 |
| A5 | Fold AuthService into `pi-kernel` only (no `auth-models`) | **Rejected** — §30 / D8 |
| A6 | Load project `.pi/extensions` for custom providers | **Rejected** — empty loader held |

**Can this be simpler?** One Pi-importing CLI package fails DEC-0133. Folding router into `pi-kernel` fails §30 / D8. `~/.pi/agent` as ship store fails D1. The A1 split (owned types in `auth-models`, Pi wrap in `pi-kernel` only) is the simplest design that meets the ACs.

### 2. Package + import boundary (DQ5 / D8 / AC-1)

- Path: **`standalone/packages/auth-models`**. npm name `@its-magic/auth-models`, `private: true`, `version: 0.0.0`, `type: module`, `engines.node >=22.19.0`, export `./src/index.ts`.
- **No Pi imports.** `package.json` must not depend on `@earendil-works/pi-*` or `@its-magic/pi-kernel`. Existing Biome `noRestrictedImports` already denies Pi outside `pi-kernel`; extend the US-0133/US-0134 grep to also deny Pi inside `auth-models`. Do **not** add a Biome override for `auth-models`.
- `apps/cli` imports **only** `auth-models` types/handlers for auth/models commands — never Pi modules.
- Do not amend AgentKernel isolation loader, `noTools: "builtin"`, pins, or KernelBridge. Additive only: optional `thinkingLevel` on owned `KernelCreateSessionOptions` (pi-kernel maps to SDK).
- Kit `files` continues to omit `standalone/` (compose DEC-0120 / US-0133 omit-guard).

### 3. Owned credential store (DQ1 / AC-1) — LOCKED

Ship-path `ModelRuntime.create({ authPath, modelsPath, allowModelNetwork })` against a **standalone-owned OS config directory**. Never the project tree. Never `~/.pi/agent` as the stable store. Never `.env`.

| OS | Directory (code-name `its-magic`; **AC-6: do not lock public branding**) | Files |
|---|---|---|
| Linux | `${XDG_CONFIG_HOME:-$HOME/.config}/its-magic/` | `auth.json`, `models.json`, `models-store.json` |
| Windows | `%APPDATA%\its-magic\` | same |
| macOS | `~/Library/Application Support/its-magic/` | same |

- Mode **0600-class** on `auth.json`. POSIX: `chmod 0o600`. Windows v1: user-profile `%APPDATA%` is the control (inherent user ACL). Extra Windows ACL APIs are **out of this story** (R2 later).
- Overrides: `--auth-path` / `ITSM_AUTH_PATH` must stay outside the project; project-relative paths fail-closed `AUTH_PATH_IN_PROJECT`.
- Tests: `InMemoryCredentialStore` via `ModelRuntime.create({ credentials })` — **no disk**.
- Spike-only: Pi default `~/.pi/agent/auth.json` may be read by explicit `itsm auth migrate --from-pi` when dest is absent. **Never auto-copy. Never write tokens into the repo or `.env`.**
- Isolation `agentDir` from DEC-0133 remains a runtime-owned empty dir (not `~/.pi/agent`). Auth path is independent of session `agentDir`.
- CI: `allowModelNetwork: false`. Fake-model inject seam **held**.

**Reject**: `~/.pi/agent/auth.json` as the stable ship store. **Reject**: project `.its-magic/` / `.env` credentials.

### 4. AuthRuntimeAdapter (pi-kernel) + Codex / provider matrix (DQ2–DQ4 / AC-1 / AC-2) — LOCKED

Owned Pi-facing adapter lives **only** in `packages/pi-kernel`. Pin remains `@earendil-works/pi-coding-agent@0.85.1` / `@earendil-works/pi-ai@0.85.1`.

```ts
type AuthType = "oauth" | "api_key";
type ThinkingLevel = "off" | "minimal" | "low" | "medium" | "high" | "xhigh" | "max";

interface AuthInteraction {
  prompt: (p: {
    type: "text" | "secret" | "select" | "manual_code";
    message: string;
    options?: { id: string; label: string }[];
    signal?: AbortSignal;
  }) => Promise<string | undefined>;
  notify: (event: {
    type: "info" | "auth_url" | "device_code" | "progress";
    url?: string;
    userCode?: string;
    verificationUri?: string;
    message?: string;
  }) => void;
  signal?: AbortSignal;
}

interface AuthRuntimeAdapter {
  createRuntime(opts: {
    authPath: string;
    modelsPath: string;
    credentials?: unknown;      // InMemoryCredentialStore in tests
    allowModelNetwork?: boolean; // false in CI
  }): Promise<void>;
  login(providerId: string, type: AuthType, interaction: AuthInteraction): Promise<void>;
  logout(providerId: string): Promise<void>;
  checkAuth(providerId: string, opts?: { refresh?: boolean }): Promise<{ type: AuthType } | null>;
  registerProvider(name: string, config: unknown): void;
  getModel(provider: string, model: string): unknown | null;
}
```

- Production login is **three-arg** `login(providerId, type, interaction)` — not one-arg `login("openai-codex")` and not Pi TUI `/login`. Codex: `providerId = "openai-codex"`, `type = "oauth"`; CLI wraps browser (`notify auth_url` + `manual_code`) or device_code (`https://auth.openai.com/codex/device`). **Never open a browser from CI.**
- `CredentialSynchronizationError` → fail-closed `AUTH_SYNC_FAILED`. Do **not** retry the credential mutation blindly.
- `setRuntimeApiKey` is **one-run only** (not persisted). `itsm auth login` API-key persists via `login(..., "api_key", interaction)` / CredentialStore.
- `registerProvider` maps to the 0.85.1 **in-process** provider registration API (`ModelRuntime` method if present; otherwise coding-agent `registerProvider`). **Never** via `DefaultResourceLoader` project `.pi/extensions` discovery (empty loader held).
- Additive session option: `KernelCreateSessionOptions.thinkingLevel?: ThinkingLevel` — pi-kernel maps to `createAgentSession({ thinkingLevel })`. Do not couple to `TOKEN_PROFILE`.

Minimum AC-2 set **without** loading project `.pi/extensions`:

| Category | v1 ids | Mechanism |
|---|---|---|
| Codex OAuth | `openai-codex` | built-in OAuth |
| API-key | `openai`, `anthropic`, `google`, `openrouter` | built-in API key (`auth.json` / env — **not** `.env` injection) |
| Chinese | `deepseek`, `kimi-coding`, `zai` (+ `zai-coding-cn`), `minimax` (+ `minimax-cn`), `qwen-token-plan*` | built-in API key |
| Local OpenAI-compatible | operator `ollama` / `lmstudio` / `vllm` | owned `models.json` (`api: "openai-completions"`) |
| Custom corporate gateway | operator id | owned `models.json` (headers/`baseUrl`/`authHeader`) **or** adapter `registerProvider` for custom OAuth/SSO |

### 5. ModelRouter 6-step + thin catalog (DQ5 / DQ6 / AC-3) — LOCKED

Owned types live in `standalone/packages/auth-models` (no Pi imports). Slug shape: actual Pi `provider/model`. Cursor aliases (`fast` / `inherit`) are **not** standalone runtime slugs.

```text
CLI argv `--model provider/model`
  > phase-local catalog/config override
  > role catalog `roles[<phase→role>]`
  > critic overlay (critic resolve only)
  > tier/catalog `tiers[cheap|balanced|strong]`
  > runtime default (operator default slug, else first available; CI = fake-model)
```

```ts
type ResolveSource =
  | "cli"
  | "phase-local"
  | "role-catalog"
  | "critic-overlay"
  | "tier-catalog"
  | "runtime-default";

interface ModelResolveProvenance {
  source: ResolveSource;
  slug: string;
  provider: string;
  model: string;
  thinkingLevel: ThinkingLevel;
  criticPin: boolean;
  degradedMode: boolean;
  thinkingClamped: boolean;
  thinkingForced?: boolean;
}

interface ModelRouter {
  resolve(input: {
    argvSlug?: string;
    phase?: string;
    role?: string;
    criticResolve?: boolean;
    catalog: StandaloneCatalog;
  }): { slug: string; thinkingLevel: ThinkingLevel; provenance: ModelResolveProvenance };
}
```

Unknown slug → fail-closed `MODEL_OVERRIDE_SLUG_UNKNOWN` / `MODEL_ROLE_SLUG_UNKNOWN`. Keep `AUTH_*` for credentials vs `MODEL_*` for routing. Do **not** invent `AUTH_CROSS_MODEL_*`.

Thin standalone catalog JSON (gitignored local; **not** US-0138 `RuntimeConfig`; **not** Cursor catalog SOT):

- Path: `.its-magic/model-catalog.local.json` (gitignored; slugs/thinking only). Secret-shaped keys fail-closed (no tokens in catalog).
- Schema: `schema_version` + `tiers` + `roles` + optional `phases` + `critic` + per-role `thinking`.
- Operator may copy names from `.cursor/model-catalog.local.json` only after rewriting to Pi `provider/model`.
- Missing catalog → fall through to runtime default (CI fake-model).

### 6. Thinking clamp + critic pin (DQ7 / DQ8 / AC-4 / AC-5) — LOCKED

- Thinking is session-scoped via `createAgentSession({ thinkingLevel })`, not encoded in the slug, not `TOKEN_PROFILE`, not per-prompt as v1 SOT.
- **Clamp (not fail-closed)**: if requested level is `null` on `thinkingLevelMap`, clamp to nearest supported **lower** level and set `thinkingClamped=true` in provenance. Do **not** emit `MODEL_THINKING_UNSUPPORTED` as the v1 default (closes us0135rsc-challenger-001 DQ7).
- Always-thinking models (`off: null`): keep provider default + provenance `thinkingForced=true`.
- Critic pin: thin catalog `critic.model` (or CLI critic overlay) honored on critic resolve only (step 4). Same normalized `provider/model` as producer → `degraded_mode=true` / **`CROSS_MODEL_DEGRADED_MODE`**. Reuse that code. Not a hard stop. Not auto-next-slug. Never claim false cross-model independence. US-0144 owns critic **session spawn**.

### 7. CLI + diagnostics (DQ9 / AC-1 / AC-6) — LOCKED

| Command | Behavior |
|---|---|
| `itsm auth list` | configured providers; no tokens |
| `itsm auth login <provider> [--type oauth\|api_key]` | adapter `login`; print URL/device code; read paste |
| `itsm auth logout <provider>` | adapter `logout` |
| `itsm auth migrate --from-pi` | spike-only; dest absent; never auto |
| `itsm models list` | catalog + available slugs; no tokens |
| `itsm models test <provider/model>` | `checkAuth` + catalog presence; **no paid completion** |
| `itsm models test <provider/model> --live` | operator-opt-in paid completion; **never CI** |

Diagnostics: `{ provider, model, auth: configured|missing, health: ok|fail }` — **no tokens**, no Authorization/Cookie, no `.env` reads.

### 8. OAuth refresh isolation (DQ10 / AC-7)

Refresh stays inside Pi `ModelRuntime` / `pi-ai`. Tokens must never appear in `session.prompt` text, audit payloads, logs, or repo artifacts. Redact `Authorization` / `Cookie` / `sk-` / `access` / `refresh`. Never read `.env` (US-0137 owns tool deny). CI fake-model means **no live secrets**. Contract test spies prompt + audit JSON for token-shaped strings after a stubbed refresh.

## Consequences

- Execute implements A1 without reopening DQ1–DQ10, amending isolation/`noTools`/KernelBridge, enabling project `.pi/extensions`, treating Cursor aliases as runtime slugs, or designing US-0136+.
- Credentials never land in the repo or `.env`.
- Critic same-slug is reported as `CROSS_MODEL_DEGRADED_MODE`, not independence.
- Fake-model CI remains the default; `--live` stays operator-only.
