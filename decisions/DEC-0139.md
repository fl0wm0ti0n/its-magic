## Context

Standalone runtime has no `CodeIntelligenceProvider`, no AFT read adapter, no `code_context(task)` fusion, and no per-phase bounded context pack. PolicyEngine already stubs `itsm_search`/`outline`/`symbol`/`references`/`callers`/`impact` (DEC-0137). Config already owns `TOKEN_PROFILE` / phase include-exclude / `SOVEREIGN_MEMORY` (DEC-0138). Kit `materialize_codebase_map.py` (US-0082) remains the derived-map bootstrap.

R-0132 locked DQ1–DQ10 and recommended **A1**. This DEC accepts A1 and closes architecture-owned pins: two-package split, nested AFT read sidecar + version pin, unstub existing tool names, deterministic ranking + TOKEN_PROFILE caps, assembler exclusion, pack envelope (not DEC-0038), derived-map compose, benchmark with its-indexd OUT, partial-pack degradation, and twelve `test_us0139_*` markers. It also closes research-critic informational NBs (`us0139rsc-*`).

### 2. Packages + import boundary (DQ1 / AC-1)

- Paths: **`standalone/packages/code-intelligence`** (`@its-magic/code-intelligence`) and **`standalone/packages/context-engine`** (`@its-magic/context-engine`). Both `private: true`, `version: 0.0.0`, `type: module`, `engines.node >=22.19.0`, export `./src/index.ts`. Workspaces glob `packages/*` already covers them. **Execute owns the package files** — this DEC does not create them.
- **No Pi imports.** Neither `package.json` may depend on `@earendil-works/pi-*` or `@cortexkit/aft-pi`. Extend US-0133..0138 grep to deny Pi inside both packages. Type-only imports from `@its-magic/config` are allowed. Do **not** import PolicyEngine internals. Do **not** add a Biome override.
- AFT adapter is **nested** under `code-intelligence/src/aft/` as the v1 `CodeIntelligenceProvider` implementation. Do **not** publish `@its-magic/aft-adapter` this story. Backend swap remains an internal constructor.
- `context-engine` calls the provider interface, not AFT protocol. ToolBroker **injects** a `CodeIntelligenceProvider` into search-tool handlers.
- Kit `files` continues to omit `standalone/` (DEC-0120). Do **not** stub `runtime-core` this story.

### 3. Provider interface (DQ1 / AC-1)

`CodeIntelligenceProvider` exposes: `status`, `search` (lexical+semantic), `outline`, `symbol`, `references`, `callers`/`callees`, `impact`, `diagnostics`, `refresh(changes?: Path[])`. Agent must not notice a later backend swap.

### 4. AFT process model (DQ2 / AC-2) — LOCKED

- **Sidecar** persistent warm AFT process **per repo root**, JSON-over-stdio (BridgePool analog). Not in-process WASM this story.
- Adapter-owned pin: **`AFT_BINARY_VERSION="0.55.1"`** (EARLY_RESEARCH analog of `@cortexkit/aft` 0.55.1; **not** a runtime npm dependency of either package).
- Resolve ladder: cache → npm platform package matching the pin → PATH. Windows + Linux required for the live adapter; **CI uses a fake adapter** (no live binary, no network, no GitHub release, no cargo). Optional operator `doctor` is out of CI.
- Do **not** import `@cortexkit/aft-pi`, `@cortexkit/aft-opencode`, or `@cortexkit/aft-bridge`.
- **Read-only allowlist** mapped onto the provider. **Never register or forward** `write`/`edit`/`apply_patch`/`aft_delete`/`aft_move`/`aft_transform`/`aft_refactor`/`ast_grep_replace`. If the binary exposes them, the adapter returns **`INTEL_MUTATION_DENIED`** and does not forward. Production mutations stay `itsm_edit`/`itsm_write`/`itsm_patch` via existing PolicyEngine (compose, do not rewrite).

### 6. Per-phase exclusion (DQ4 / AC-4) — LOCKED

- **Session assembler** in `context-engine` owns include/exclude. Provider is retrieval-only and must not inject transcripts, `.env`, secrets, whole backlog, or command markdown.
- Default exclude: previous-role transcripts, secrets/credential blobs, whole backlog/history, giant static prompts, `.env`. Consume `AUTO_PHASE_INCLUDE` / `AUTO_PHASE_EXCLUDE` and `SOVEREIGN_MEMORY` as injected flags (do not import config loaders).
- When `SOVEREIGN_MEMORY=1`, inject a size-capped digest of **1500 tokens** only. HOT/WARM/COLD compose US-0053 / US-0096 (narrow-read, not rewrite).
- Compose US-0136: assembler runs in a **fresh** role session; fill the attestation `context_pack_hash` stub with this pack `content_hash`. Do **not** rewrite SessionSupervisor / RoleCatalog internals. **Never** read `.env`.

### 7. Source refs + content hash (DQ5 / AC-5) — LOCKED

Owned pack envelope, **not** an extension of `compute_strict_proof_hash` / DEC-0038.

Schema (v1): `{ schema_version, token_profile, source_refs: [{ kind, path, start?, end?, snippet_sha256 }], ranked_ids, exclude_set_hash, content_hash }`.

Algorithm: SHA-256 of canonical sorted-key JSON of those fields **excluding** `content_hash`. Snippets hashed; **full source and secrets never persisted**.

Persist: gitignored runtime JSON under the existing isolated `agentDir` analog (compose DEC-0133). Optional evidence pointer (path + hash) in phase artifacts. **SQLite deferred** to US-0140. Python validators ignore unknown sidecar keys (compose US-0136).

### 8. Derived codebase-map (DQ6 / AC-6) — LOCKED

**Compose** `scripts/materialize_codebase_map.py` (US-0082 / DEC-0065 / R-0060). Do **not** rewrite the Python contract, sentinel `<!-- its-magic:codebase-map-bootstrap v1 -->`, `[CODEBASE_MAP_OK]`, or `CODEBASE_MAP_BLOCKED:*`.

Fresh / missing map → invoke materializer. Bootstrap-sentinel maps may be refreshed by the materializer as today. **Non-bootstrap** operator maps: **preserve body**; write coverage/version as sibling gitignored **`docs/engineering/codebase-map.meta.json`**. Map is **derived**, not the index database. US-0076 freshness compose-only.

### 9. Benchmark; its-indexd OUT (DQ7 / AC-7) — LOCKED

Harness under `standalone/tests/fixtures/code-intel` + a `bench` entry exported from `code-intelligence` (fake-model, fake-AFT). Measures §17.7: NL lookup, exact symbol, callers, tests, impact, cross-language ref, recent changes, fixture “monorepo” latency, token use, stale-index recovery.

Live AFT / paid embeddings **never CI**. **`crates/its-indexd` remains OUT**. Evidence that could later open a story: documented AC-7 failures on latency/coverage that the AFT read adapter cannot recover after N measured runs. This story does not author that crate.

### 10. Degradation + incremental refresh (DQ8 / AC-8) — LOCKED

**Partial pack + reason codes**, not fail-closed empty context when a backend is down. Silent empty pack is forbidden.

Reason-code family **`INTEL_*` / `CONTEXT_*`**: `INTEL_AFT_UNAVAILABLE`, `INTEL_LSP_UNAVAILABLE`, `INTEL_EMBEDDINGS_UNAVAILABLE`, `INTEL_INDEX_STALE`, `INTEL_INDEX_UNAVAILABLE`, `INTEL_MUTATION_DENIED`, `CONTEXT_EXCLUSION`, `CONTEXT_BUDGET`. Fallback order: AFT read → lexical/git/artifact-only. Embeddings optional; lexical+structure still produce a pack.

`refresh(changes?: Path[])` is incremental. Stale index: serve pack with `INTEL_INDEX_STALE` and trigger refresh; do not block the phase on AFT health.

Fake-model CI **held**.
