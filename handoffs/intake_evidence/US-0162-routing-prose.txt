Title: Token optimization and host-neutral model routing v2

Summary: As an operator, I want typical its-magic runs to use fewer input tokens and to choose a model per role, phase, and task class from inside its-magic. Phase context packs replace full memory reads. Large memory documents are sharded. Machine evidence stays out of prompts. Always-on rules shrink to a small kernel that still keeps mandatory quality gates. Handoffs become deltas. Memory audit is deterministic first. Unchanged reads inside a phase are deduplicated. Model routing is owned by its-magic and can use local OpenAI-compatible endpoints, OpenAI, OpenRouter, KIE.ai, and Anthropic or further providers in one run, with a complexity router, capability checks, fallback chains, and a compact routing log. TOKEN_PROFILE stays separate from the model profile. Existing quality, QA, UAT, release, isolation, and strict-proof gates stay.
