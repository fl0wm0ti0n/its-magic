## Locked design (A1)

| Pin | Rule |
|---|---|
| Router | `scripts/model_routing_lib.py` owns `.its-magic/model-routing.json`. An absent file keeps `resolve_model_for_phase` unchanged. A present file is the source of truth. Order: explicit invocation, task, phase, role, complexity, then global default. `MODEL_<PHASE>=<slug>` maps to `{provider: "host-catalog", model: <slug>}`. `MODEL_TIER_<PHASE>` with no `MODEL_<PHASE>` maps cheap, balanced, and strong onto profiles cheap, balanced, and expert. Provider and model stay separate. OpenAI, OpenRouter, LM Studio, KIE.ai, and Anthropic results are not rewritten into a Cursor alias. |
| Pack | `scripts/build_phase_context.py` writes `.its-magic/runtime/context-packs/<run_id>/<phase>.json`. It holds the active story or bug, relevant acceptance criteria, current goal, current sprint or task, the relevant architecture section, relevant decisions, the previous-phase handoff delta, changed files or symbols, and open blockers. Hard caps live in `.its-magic/context-budget.json`: initial 6000, expansion 4000, max expansions 2, max single artifact 3000. `TOKEN_PROFILE=lean` uses 3000, 2000, 1, and 3000 inside those caps. `balanced` and `full` use the hard caps. `full` is not unlimited. Over the single-artifact cap, the builder returns a section or symbol pointer. `docs/engineering/phase-context.md` stays the pointer table. Read order is pack, then a targeted read, then at most two expansions. |
| Shards | The DEC-0054 archiver stays unchanged. Backlog and acceptance are not added to the triad. The prompt surface is the pack. Execute moves only the active item to `docs/engineering/architecture/US-xxxx.md` or `docs/engineering/architecture/BUG-xxxx.md` and leaves a short index stub in the hot file. Backlog and acceptance stay one file each. The pack copies the active heading. The pack's state slice is active story, phase, sprint or task, objective, blockers, next action, and refs. |
| Evidence | The DEC-0038 6-tuple and `compute_strict_proof_hash` stay. Proof bodies, isolation proof, token metrics, hashes, validator evidence, and archive verification are JSON or JSONL under `.its-magic/runtime/`, `.its-magic/evidence/`, and `.its-magic/metrics/`. `state.md` keeps `runtime_evidence_ref` and `token_metrics_ref`. The pack stores those refs and a `pack_hash` (SHA-256 of the pack's canonical JSON). `pack_hash` is not a runtime proof. |
| Kernel | `.cursor/rules/core.mdc` keeps the eight kernel lines. Phase commands, agents, skills, and the runbook replace a pasted copy with one pointer to the kernel. No generator. `template/.cursor/rules/core.mdc` is updated in the same change. QA, UAT, release, isolation, and strict-proof gates stay named and non-suppressible. |
| Handoffs | Delta fields are story, from, to, changed, open, required_reads, and do_not_reload. A typical handoff stays a few hundred tokens. |
| Audit | `scripts/memory_audit_deterministic.py` runs git diff, hash comparison, cross-reference validation, status validation, then schema validation. A clean result records `model_calls=0`. A model runs only when that helper returns an unresolved semantic question. |
| Dedup | `.its-magic/metrics/read-dedup.jsonl` records path, sha256, section or symbol, and estimated_tokens. The same path, sha256, and section in one phase is not fully read twice. Large means `estimated_tokens >= 3000`. Duplicate large reads divided by large reads stay under 0.10. The ledger is not copied into `state.md`. |
| Providers | The routing file holds profiles, roles, phases, tasks, and providers. Each provider has type, optional base_url, and `api_key_env` matching `^[A-Z][A-Z0-9_]*$`. Types are openai, openai-compatible, and anthropic. LM Studio, OpenRouter, and KIE.ai use openai-compatible. KIE `base_url` is operator-supplied. Tests use a fixture URL. Do not invent a production KIE URL. Do not read `.env`. Each phase resolves independently. The committed example contains no secrets. |
| Complexity | The classifier is deterministic and makes no model call. First match wins: critical, high, trivial, low, otherwise normal, using the `complexity.thresholds` defaults in R-0169 DQ9. Profiles may declare code, tools, reasoning, and large_context. An incompatible profile is not used. The router records one of `MODEL_UNAVAILABLE`, `MODEL_CAPABILITY_MISMATCH`, `MODEL_CONTEXT_TOO_SMALL`, `PROVIDER_UNAVAILABLE`, or `MODEL_RATE_LIMITED` in `.its-magic/metrics/routing.jsonl`. `state.md` may hold `routing_evidence_ref` only. Escalation defaults `max_failures` 2. After the cap the router stops and keeps the last code. |
| Axes | `TOKEN_PROFILE` and the model profile stay separate. `lean` with an expert profile, and `balanced` with a local profile, are both valid. Existing `MODEL_*` keys are not deleted. US-0139 stays DONE. The pack does not call `@its-magic/context-engine`. |
